## 指令正文

你在晓晓工作台的本机仓库工作。开始前先读根目录 `AGENTS.md` 和 `工作台功能保留规则.md`，并核对当前安装版本。这项任务只做本机工具的串联，不改生成、匹配、任务恢复和扣费相关逻辑。

### 用户想要什么

用户现在的手工流程：

- **图片**：原图 → Upscayl 高清 → 用自己开发的压缩工具压小体积（不降清晰度）→ 删掉中间那份很大的高清图 → 用压缩后的高清图去生成视频。
- **视频**：生成的视频 → Topaz Video Enhance AI 高清 → 同一个压缩工具压小体积 → 删掉中间那份很大的高清视频 → 进剪映。
- 压缩工具在：`<把这里换成需求文档第 8 条里的压缩工具安装目录>`

用户希望在工作台里一键完成，不用在三个软件之间手动倒文件，也不用手动删中间文件。

### 第一步：只调查，不写代码，先向用户汇报

1. 查清三个工具的版本、安装位置、能不能不开界面调用：
   - **Upscayl**：安装目录里通常带一个命令行程序和模型文件夹。确认是否存在、怎么传参，以及用户平时用的模型、放大倍数、输出格式。
   - **Topaz**：先确认到底是旧的 Video Enhance AI 还是新的 Topaz Video AI，两者的命令行方式不同。确认命令行能不能用、需要什么环境变量、在已登录授权的状态下能否正常跑，以及用户平时用的模型、倍数、帧率设置。
   - **压缩工具**：看目录里有哪些可执行文件、有没有帮助参数或配置文件。确认：支不支持命令行；是否同时支持图片和视频；输出是**另存新文件还是覆盖原文件**；输出文件怎么命名。它是用户自己开发的，如果没有命令行，就问用户能不能加一个，不要用模拟点击界面的办法。
2. 每个工具用一个小样本实测一次。样本用用户指定的、不重要的文件的**副本**。记录：耗时、显存占用、输出体积、输出文件能否被工作台和剪映正常打开。
3. 向用户汇报：每个工具属于「能全自动」「只能半自动（帮用户打开软件并把文件放进去）」还是「不能接」，以及你建议怎么串。**等用户确认后再进入第二步。**

### 第二步：实现（用户确认调查结论之后）

按调查结论做。用户期望的用法如下，做不到的部分如实说明并给替代办法。

**入口**
- 资产库图片右键「高清并压缩…」，支持多选。
- 视频卡片右键「高清并压缩…」，支持多选。
- 如果「补漏台」已经上线并且有「导出采用清单」，在它旁边加「送去高清…」。

**流程**
- 加入本机队列 → 高清 → 压缩 → 校验 → 回链到工作台 → 清理中间文件。
- 一次只跑一个任务（显卡独占）。可暂停、可取消。重启工作台后队列还在。失败的保留原因，可以重试。
- 队列有一个看得见的入口，显示正在处理哪个文件、进度、剩余数量。

**图片怎么回到工作台**
- 用高清压缩后的图替换原资产的图片文件，保留资产的身份、名称、分类、角色归属、优先和禁用状态。沿用规则 29 的「替换图片」机制，支持撤销。
- 被替换下来的原图去哪，第一次让用户选并记住：留在禁用区（现有行为），或进 Windows 回收站。

**视频怎么回到工作台**
- **不替换**工作台里原视频的记录和文件。原视频的任务身份、提示词、参数、参考素材都不动。
- 高清压缩后的文件作为这条视频的「高清版」，存到用户指定的输出文件夹，文件名带视频编号，能直接拖进剪映。
- 在视频详情里显示「高清版：有 / 无」和「打开所在位置」。

**清理**
- 只有最终文件校验通过（能打开、时长和分辨率正确、体积合理）之后，才清理中间文件。
- 清理一律进 Windows 回收站，不做永久删除。
- 临时文件放 `F:\WORKBENCH_TEMP`，不写 C 盘（规则 5）。

### 必须避开的坑

- **硬链接分身**：「保存视频快捷…」存出来的 `.mp4` 是硬链接分身，和工作台里的原视频是同一份数据（规则 15）。对分身做覆盖写入，会连带改掉工作台里的原视频。所以高清和压缩**一律输出到新文件**，任何一步都不能原地覆盖输入文件。如果压缩工具只能覆盖，就先复制一份再压缩，并在汇报里说明。
- 不改动工作台的项目目录结构和现有索引文件的已有内容；需要记录"高清版在哪"时，用新增字段。
- 队列运行期间不自动发起任何生成任务，这项功能不涉及积分。
- 不把软件的授权文件、用户的素材和视频复制进仓库，不上传。
- 不顺带修改这次没提到的功能、入口和默认行为（规则 1）。

### 验收（在用户电脑上实测后逐条报告）

| 操作 | 应该看到 |
| --- | --- |
| 右键一张资产图片 →「高清并压缩」 | 完成后资产显示的是新图；名称、分类、角色、优先、禁用都没变；`Ctrl+Z` 能恢复旧图 |
| 用这张新图生成一条视频（**需要用户当次授权扣费**） | 提交、上传到画布、生成正常，详情里的参考素材是新图 |
| 右键一条视频 →「高清并压缩」 | 输出文件夹出现带编号的高清压缩文件；工作台里原视频能照常播放、重新编辑；详情显示有高清版 |
| 对一条存过硬链接分身的视频做同样操作 | 工作台原视频和分身的内容、体积都没有变化 |
| 多选 5 个文件加入队列，中途退出再打开工作台 | 队列还在，可以继续 |
| 处理中点取消 | 当前任务停止，不留下半截输出文件，原文件完好 |
| 高清或压缩失败（比如把输出盘填满来模拟） | 报出原因，原文件完好，中间文件没有被提前删掉 |
| 全部完成后检查磁盘 | 中间的大文件已经在 Windows 回收站里，F 盘临时目录已清空 |
