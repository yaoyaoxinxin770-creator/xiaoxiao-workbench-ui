## 用户要达到的结果

用户的分镜稿里，同一场戏有时写两个版本。第二个版本的视频编号用字母分支，例如 `V4-B1`、`V4-B2`、`V4-B3`，表头类似：

```
【视频编号V4-B1｜剧本4-4【第2版】（客厅 日/内）前段】
```

现在把这样的稿子导进工作台，三组的编号都会变成 `V4`：导入弹窗写"识别到……V4、V4、V4"，三张卡片角标一样，标题都是「视频 V4」，按名称排序时还会跑到 `V4-01` 前面。内容没有丢（导入按正文去重，三组都在），但分不清谁是谁。

改完后：

- 导入弹窗写"识别到 9 组：V4-01、V4-02、V4-B1、V4-B2、V4-B3、V4-03……"。
- 卡片角标、生成成功通知、截帧名称、即梦画布节点名、确认弹窗里的编号，都是 `V4-B1`。
- 以前已经导入、被存成 `V4` 的那几组，打开工作台后自动改回 `V4-B1`、`V4-B2`、`V4-B3`，不用删了重导。
- 其他写法的编号（`25`、`V01`、`V4-01`、`12-3`）和现在完全一样。

## 交互与界面

没有新界面。只有三处文字会变：

1. **导入视频组弹窗**的"识别到 N 组：……"列表，显示完整编号。输入框里的示例文字可以补一个带字母的例子（现有文字是"使用【视频编号25｜第25组…】、【视频编号V01｜…】或 视频编号25 分组"），不补也行。
2. **所有显示编号的地方**跟着变：卡片角标、生成成功通知「视频 V4-B1 生成成功」、截帧名「V4-B1-帧-00m03s05」、确认弹窗的编号角标。
3. **存量修正的一条提示**（只在确实改到了旧数据时出现一次）：
   - `message.info`：`已补全 3 个视频组的编号：V4 → V4-B1、V4-B2、V4-B3`
   - 超过 5 组时写成 `已补全 12 个视频组的编号（如 V4 → V4-B1）`
   - 没有需要改的组时什么都不提示。

没有新增入口、空状态、批量操作。撤销：存量修正不进撤销历史（它不是用户操作），靠实施前的备份回退。

## 支持哪些编号写法

现有写法：可选的 `V` 开头 + 数字，后面可以跟若干个「`-` + 数字」。

改成：可选的 `V` 开头 + 数字，后面可以跟若干个「`-` + 一段」，**每一段是"可选字母 + 数字 + 可选字母"**。

```
现在   [Vv]?\d+(?:-\d+)*
改成   [Vv]?\d+(?:-[A-Za-z]*\d+[A-Za-z]*)*
```

| 表头里写的 | 现在读到 | 改完读到 | 说明 |
| --- | --- | --- | --- |
| `V4-B1` | `V4` | `V4-B1` | 本单要修的 |
| `V4-B12` | `V4` | `V4-B12` | |
| `V4-01b` | `V4-01` | `V4-01b` | 数字后面带字母的变体 |
| `25`、`V01`、`V4-01`、`12-3` | 不变 | 不变 | 纯数字段的结果和现在一样 |
| `5-Seedance版` | `5` | `5` | 连字符后面那段没有数字，不算编号的一部分 |

- 每段必须含数字，所以不会把编号后面跟着的英文单词吞进来。
- 只认半角英文字母。中文、全角字母不进编号（和现在一样在那里截止）。
- 不改大小写：前端按原样保留；即梦节点名现有的"转大写"保持不变。

## 数据与旧项目

| 数据 | 变化 |
| --- | --- |
| 字段结构 | 不变。`StudioVideoGroup.number`、`title` 仍是字符串 |
| 新导入的视频组 | `number` 存完整编号，`title` 是「视频 完整编号」 |
| **已导入、编号被截断的视频组** | 自动补全，规则见下 |
| 生成记录（提示词、任务、成片） | 不改。角标本来就是每次从提示词表头现读的，正则改对以后自然显示完整编号 |
| 已建好的即梦 / 小云雀画布节点 | 不改名。只影响以后新建的节点 |
| 账号、任务身份、扣费 | 无关 |

**存量修正的规则**

对 `groups` 和 `removedGroups`（回收区里的组，恢复后也应当是对的）里的每一组：

1. 取这一组 `prompt` 里第一处行首的「视频编号」。
2. 用**旧写法**读一次，得到「旧编号」；用**新写法**读一次，得到「新编号」。
3. 只有同时满足这三条才改：
   - 这一组存着的 `number` **正好等于旧编号**（说明它就是当初被截断存下来的）；
   - 新编号读得到；
   - 新编号和旧编号不一样。
4. 改法：`number` 换成新编号；`title` 如果正好是「视频 旧编号」，换成「视频 新编号」，否则不动（用户自己改过的标题保留）。
5. 其他字段一律不碰：`id`、`logIds`、`projectId`、`folderId`、`createdAt`、`color`、`colors`、`bindings`，以及这一组在列表里的位置。

- 时机：工作台启动、视频组数据读出来之后跑一次。
- 天然幂等：改过的组，`number` 已经不等于旧编号，第二次不会再动。不需要另存"已迁移"标记。
- 用户手动改过编号的组不会被误伤（存着的值不等于旧编号，就不满足条件）。
- 旧写法要作为常量留在代码里，只给这一步用。
- 回退：装回上一稳定版后，`number` 是 `V4-B1` 的组能正常打开（旧代码把它当普通字符串）；只是角标又会被旧正则读成 V4。请本机在验收时顺带确认装回旧版不报错。
- 备份（规则 4）：实施前按本机 `AGENTS.md` 的办法备份工作台数据目录，要包含视频组数据（`video_studio` 那一份）。
