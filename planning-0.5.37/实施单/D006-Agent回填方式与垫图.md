## 用户要达到的结果

用户在某条视频上点机器人图标，让 Agent 改提示词。Agent 给出「修改后全文」。

**现在**：点「填入提示词框」只填文字。编辑区里当时挂着什么素材就是什么素材——可能是另一组的，也可能是空的，然后被自动匹配配上后期的衣服。用户要自己把原视频的素材一张张找回来。

**改完后**：

1. 点「填入提示词框」，默认把这条视频**原片的素材**一起载入，再填入改好的提示词。想保持编辑区现有素材，可以切到「只填提示词」。
2. 给 Agent 发过的图（比如一张用来说明站位的截帧），如果改好的提示词要用它当垫图，回填时自动挂到参考区。
3. Agent 对话里发出去的图，可以直接拖到视频提示词区，加为参考图。

## 交互与界面

### 一、回填方式

**按钮不改名、不挪位置。** 回复卡片底部仍是这两个按钮，文字和现在完全一样：

```
[✓ 填入提示词框 ▾]   [▶ 填入并开始创作]
素材：将载入 V4-10 · 1 的原片素材　改
```

变化只有两处：

1. 第一个按钮右侧多一个小下拉角标 `▾`。
2. 按钮下方多一行小字，写明这次回填会怎么处理素材。行尾的「改」和上面的 `▾` 打开同一个菜单。

**菜单**

```
● 沿用原片素材
  载入这条视频生成时实际用的图、音频和参数
○ 只填提示词
  编辑区现在有什么素材就留什么
```

- 选哪一项只是**切换方式**，不会立刻回填。选完后状态行跟着变，用户再点按钮。这样不会因为点菜单而误填。
- 选择会被记住，对之后所有回复卡片生效，重启后保持。默认「沿用原片素材」。
- 「填入并开始创作」用同一个方式。

**状态行写什么**

| 情况 | 状态行 |
| --- | --- |
| 方式 = 沿用原片；编辑区不是这条视频 | `素材：将载入 V4-10 · 1 的原片素材　改` |
| 方式 = 沿用原片；编辑区已经是这条视频所在的组，而且挂着素材 | `素材：沿用编辑区现有的（已是 V4-10 的素材）　改` |
| 方式 = 沿用原片；关联的是一个还没生成过的组 | `素材：这一组还没有原片，按提示词自动匹配　改` |
| 方式 = 只填提示词 | `素材：保持编辑区现有素材不变　改` |
| 纯聊天、没有关联视频 | 不显示状态行和下拉角标，只有「只填提示词」这一种行为，和现在一样 |

**「沿用原片素材」具体做什么**

1. 确定是哪条视频（见下面"关联了多条视频时"）。
2. 如果编辑区已经在这条视频所在的组上、并且挂着素材：**不重新载入**，保留用户在编辑区已经做的调整（比如刚手动换过一张图、加过一张垫图）。这和现有的"点视频小标签"的行为一致。
3. 否则：把这条视频生成时实际用的参考图、音频、参考视频、首尾帧和参数载入编辑区，和点它的「重新编辑」一样。编辑区里另一组没发出去的修改先暂存，切回去还在——沿用现有的同次审阅暂存。
4. 填入 Agent 改好的提示词和参数。
5. 生成后归到原视频组，成为新的一版（规则 20）。

**填入之后的两种情况**

- 新提示词里多出来的人物、道具（原片里没有）：显示成现有的虚线「待补素材」卡。顶部自动匹配开着时，只给这些新名字补素材，按 D003A 的顺序；**已经载入的原片素材不动**。
- 新提示词里不再提到的原片素材：留在参考区，沿用现有的提示（黄色描边加红色小叹号，说明"当前提示词正文中未检测到该素材引用"），由用户决定删不删。

**提示**

- 沿用原片并发生了载入：`已填入，并载入 V4-10 · 1 的原片素材（5 图 1 音）。可按 Ctrl+Z 撤回`
- 沿用原片但没有重新载入：`已填入提示词框，编辑区素材保持不变。可按 Ctrl+Z 撤回`
- 只填提示词：沿用现有的 `已填入下方提示词框，当前参考图片/音频保持不变（支持 Ctrl+Z 撤回）`
- 现有的"提示词面板短暂发光"和按钮变成「重新填入提示词框」、旁边出现「已填入提示词框」都保留。

**撤销**：`Ctrl+Z` 一次回到回填之前，提示词和参考素材一起恢复。

**关联了多条视频时**（例如同时关联了 V13 和 V14）

- 看改好的提示词里的【视频编号】，对上其中哪一条就用哪一条。
- 对不上、或者编号同时对上几条：状态行变成 `素材来源：V13 · 1 ▾`，下拉里列出关联的几条让用户选，默认第一条。
- 提示词里没有编号、且只关联了一条：就用那一条。

**原片素材载入失败时**

- 原文件找不到、读不出来：按规则 21 明确报错，**不回填、不开始创作**，说明是哪张素材出了问题。用户可以去重新定位，或切到「只填提示词」。
- 不能少载几张然后继续。

**「改完自动填入提示词框」**

- 现有的触发条件不变（勾选了、关联着视频、目标没变、不是纯聊天或提取类回复、有提示词）。
- 方式 = 只填提示词：和现在完全一样。
- 方式 = 沿用原片：只有当编辑区**是空的，或者已经在这条视频所在的组上**时才自动回填。编辑区正停在别的组上时不自动回填，只显示回复卡片等用户点——避免用户正在改 V13，V10 的回复一回来就把编辑区换掉（规则 48：编辑台和 Agent 关联目标互不强行绑定）。

**「填入并开始创作」的顺序**（涉及扣费，必须严格）

1. 载入素材（如需要）并等它完成；
2. 填入提示词和参数；
3. 等参考区没有正在处理或上传中的素材；
4. 这期间编辑区没有被用户切走；
5. 以上都满足，才触发「开始创作」。

任何一步失败或条件不满足，都不触发创作，并提示原因。之后是否确认、是否直接生成，仍由顶部创作方式决定，和手动点「开始创作」一样。现在"等 120 毫秒就点"的做法在需要载入素材时不够，要换成等上面几个条件。

### 二、把 Agent 对话里的图拖进视频提示词区

**哪些图可以拖**
- 用户已发出的消息下面的附图缩略图；
- Agent 输入框上方还没发出去的附件小卡（图片类）。

**怎么拖**
- 鼠标移到缩略图上变成抓手。按住拖动时，跟着鼠标的是这张图的小缩略图。
- 拖到提示词面板上方时，面板出现现有的虚线高亮（和拖入文件时相同），并显示文字 `松手加为参考图`。
- 松手：这张图加到参考区末尾。

**不想拖也可以**：鼠标停在已发出的附图上时，右上角出现一个小按钮 `＋参考`，点一下效果相同。

**加进去之后**
- 一条成功提示：`已加为参考图「V4-09-帧-00m07s12」，并存入资产 → 待确认。可按 Ctrl+Z 撤回`。图本来就在资产库里时不说"存入"。
- 参考区里新加的那张卡短暂高亮一下，让用户看到它在哪。
- 参考图名额已满时：`当前模型的参考图片名额已满`（现有文案），不加入。
- 同一张图已经在参考区时不重复加，提示 `这张图已经在参考区了`。

**用的是哪份图**

| 图的来源 | 加进参考区的是 |
| --- | --- |
| 资产库拖给 Agent 的、截帧发给 Agent 的 | 资产库里的那张原图，不新建资产 |
| 从电脑里拖进或选进 Agent 的文件（本次运行内） | 原文件，按"保留原文件位置"的方式链接进资产库 |
| 粘贴进 Agent 的（本次运行内） | 粘贴时的原始数据，和在提示词框里粘贴图片走同一套：存入「资产 → 待确认」 |
| 重启之后、且不是来自资产库的历史附图 | 只剩历史缩略图。照样能加，但提示 `这是历史缩略图，清晰度较低，建议从原文件重新添加` |

发给 Agent 的那份压缩图（D008）只是给模型看的，不用它当参考图。

**不要误触发别的拖放**
- 拖到提示词面板任何位置都是"加为参考图"，包括拖到某张已有的参考卡上——不替换那张卡。
- 不触发 Agent 面板自己的"拖入附件"，不触发资产库的"外部文件导入"或"拖图替换"。
- 拖动结束或取消后，虚线高亮清除（规则 29 对拖放反馈的要求）。

### 三、垫图自动带入

**出现条件**：这一轮用户给 Agent 发过图，并且 Agent 给出了可回填的提示词。

**界面**：回复卡片里，在两个按钮的上方多一行：

```
本轮附图　☑ [缩略图] V4-09-帧-00m07s12　☐ [缩略图] 粘贴图-143205-1　　填入时一并加入参考区
```

- 每张附图一个小卡：勾选框、缩略图、名称。点小卡任意位置切换勾选；缩略图上有放大按钮。
- 默认勾选规则：Agent 明确说用到了的图、或者图的名称出现在改好的提示词里的，默认勾上；其余不勾。
- 用户可以自己改勾选。勾选状态只属于这张回复卡片。
- 一张都没勾时，这一行后面的文字变成 `不加入附图`。

**回填时**
- 勾上的图加到参考区，规则和上面第二节"加进去之后""用的是哪份图"相同；提示合并进回填的那一条提示里，例如 `已填入，并载入 V4-10 · 1 的原片素材（5 图 1 音），另加入 1 张附图`。
- 提示词里出现了图的名称时，会在提交时被现有逻辑自动识别成 @ 引用（规则 26），不需要用户手动绑定。
- 垫图加为**普通参考图**，不放进首帧。现有限制是首尾帧不能和普通参考素材混用。
- 「只填提示词」方式下，这一行照常显示、照常生效——"只填提示词"说的是不动现有素材，用户勾选的附图仍然加进去。

**附图的名称**
- 发送时保证同一条消息里的附图名称不重复。
- 剪贴板粘贴的图常常都叫"image.png"。这类通用名在加入附件时自动改成 `粘贴图-时分秒-序号`，和提示词框粘贴图片的命名一致。这样 Agent 和用户都能指明是哪一张。

**让 Agent 知道可以这样做**
- 给 Agent 的说明里加一段：用户附了图，并且修改后的视频提示词需要把某张图当垫图或参考图时，在提示词里用 `@图片名称` 引用它，并在返回结果里列出用到的图片名称。
- 返回结果里没有这一项时，退回按"图片名称有没有出现在提示词里"判断。旧对话没有这一项，按都不勾处理。
