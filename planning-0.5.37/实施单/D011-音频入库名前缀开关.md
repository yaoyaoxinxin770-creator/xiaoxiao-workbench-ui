## 用户要达到的结果

用户常把参考音频改名成一句台词。现在用这条音频补台词，新音频的名字会变成「旧台词-新台词」，声线归属也变成那句旧台词，在音频库里既找不到也分不清是谁的声音。

改完后：

- 用户在「入库名称」旁边有一个「前缀」开关。开着是 `女主-新台词`，关掉是 `新台词`。选择会被记住。
- 不管参考音频自己叫什么，前缀和声线归属都是它**所属的角色**（例如"女主"）。
- 生成前能看到并改掉声线归属。

已确认：开关默认开；前缀用角色名。

## 交互与界面

样子见 `设计预览/04-第1-2批界面.png`（设计预览，只说明摆法和操作，名称是占位）。

位置：提示词面板「音频」区底部那一行工具栏，现有顺序是 模型标签 → 配音模式 → （音色）→ 入库名称。新增两个控件，紧跟在「入库名称」输入框后面：

```
[seed_audio_v1 · SeedAudio 1.0] [全能配音 ▾]  入库名称：[女主-这句新台词      ]  前缀 (开关)  声线归属 @女主 ✎        [清空] [收起] [开始创作音频]
```

**1. 前缀开关**

- 一个小开关，左边文字「前缀」。悬停说明：`开：角色名-台词　关：只有台词`。
- 切换时**立即重算**入库名称并填回输入框，包括用户之前手改过名字的情况——拨开关是明确的操作，应当马上看到结果。重算后名称回到"自动"状态。
- 记住上次的选择，重启后保持。默认开。

**2. 声线归属**

- 一枚可点的小标签：`声线归属 @女主 ✎`。角色名超过 8 个字时截断并加省略号，悬停显示全名。
- 点开是一个小下拉：
  - 顶部搜索框，可直接输入新名字，回车确认；
  - 下面列出当前项目里已有的角色（人物分组名，加上音频库里已出现过的声线归属，去重）；
  - 最下面一项「不归属任何角色」。
- 归属变了、且前缀开着时，入库名称跟着重算。
- 没有可用的归属时显示 `声线归属 未指定 ✎`，前缀按"无"处理。

**3. 入库名称怎么自动生成**

「台词」指音频提示词里最后一个「台词：」后面的内容，沿用现有的清理和截取（去引号和标点、去掉文件名非法字符、取前 14 个字）。

| 前缀 | 有台词 | 没有台词 |
| --- | --- | --- |
| 开，有归属 | `归属-台词` | `归属-补词`（补台词预设）或 `归属-商用音色`（4 秒商用音色预设）——沿用现有后备词 |
| 开，无归属 | `台词` | 现有后备名（`补台词情绪配音` / `路人商用音色`） |
| 关 | `台词` | 现有后备名 |

- 用户手动改过输入框后，打字改提示词不再覆盖它（现有行为，保留）。拨前缀开关或改声线归属会重算。
- 4 秒商用音色预设的固定台词（"这是我授权可商用的音色……"）不当作台词用，沿用现有的排除。

**4. 声线归属的默认值按这个顺序取**

1. 用户在这次编辑里手选的；
2. 启用的参考音频所属的角色——和音频库里那张卡片上显示的「声线归属」是同一个值；
3. 启用的参考形象所属的角色（人物分组名）；
4. 参考素材名称里第一个 `-` 前面的部分；
5. 参考素材的名称；
6. 都没有：未指定。

切换启用的参考素材时，按上面顺序重新取默认值（用户在这次编辑里手选过的话，以手选为准，直到他换了参考素材）。

**5. 其他**

- 确认弹窗（① 模式）里显示的入库名称就是输入框里的最终值，不变。
- 小窗口：这一行本来就能横向滚动，新控件跟着滚，不换行、不挤掉「开始创作音频」。
- 没有新增空状态或批量操作。
- 撤销：这是表单输入，不进撤销历史；拨回开关即可恢复。

## 数据与旧项目

| 数据 | 变化 |
| --- | --- |
| 前缀开关的选择 | 新增一项本机偏好，存法和现有的"配音保存文件夹"偏好相同（`composer-audio-mode.tsx` 里的 `AUDIO_OUTPUT_DIR_STORAGE_KEY` 那种做法） |

| 新生成音频的 `metadata.elementPerformer`、`metadata.elementManualGroup` | 改为取"声线归属"的值。现在取的是参考素材的标题，或入库名里第一个 `-` 前面的部分 |

| 任务、账号、扣费 | 无关 |

旧的参考音频没有角色信息时，按上面默认值顺序的第 4、5 步退回，结果和现在一致。

## 改动范围

| 文件 / 函数 | 现在的行为 | 要改成 |

## 验收

准备：项目里有一条参考音频，声线归属是「女主」，标题已经被改成一句台词（例如"今天不想上班"）。

| 操作 | 应该看到 |
| --- | --- |
| 启用这条参考音频，在「台词：」后输入"明天再说吧" | 入库名称 `女主-明天再说吧`；声线归属 `@女主` |
| 关掉前缀 | 入库名称立即变成 `明天再说吧` |
| 重启工作台再进音频区 | 前缀仍是关 |
| 打开前缀，把声线归属改成"男主" | 入库名称变成 `男主-明天再说吧` |
| 手动把入库名称改成"测试一下"，然后继续改台词 | 名称保持"测试一下" |
| 接着拨一下前缀开关 | 名称按规则重算 |
| 启用一张参考形象（属于"女主"），用 4 秒商用音色预设 | 入库名称 `女主-商用音色`；归属 `@女主` |
| 不启用任何参考，自己写一段带「台词：」的提示词 | 归属显示"未指定"；名称只有台词 |
| 启用一条没有角色信息的旧音频，标题"路人甲-你好" | 默认归属"路人甲" |
| 生成一条（**需当次授权**） | 音频库「已生成」里出现这条，卡片上的声线归属和生成前显示的一致；能 @ 引用、能拖出到剪映 |
| 以前生成的音频 | 名称和归属都没有变化 |
| 四套皮肤；主窗口 1100 像素宽 | 开关和标签清楚；这一行可横向滚动，「开始创作音频」始终可见 |

相关的已有测试入口：`desktop-app/test-audio-name-match.mjs`、`test-audio-drag-and-hover-buttons.mjs`。建议给第 1 步的两个函数加用例，覆盖上面两张表——风险是以后改预设或后备词时把"台词-台词"带回来。
