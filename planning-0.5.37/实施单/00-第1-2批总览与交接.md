## 界面手感约定

用户对本批的明确要求是"使用方便、用着舒服"。下面十二条适用于本批所有界面改动，每张实施单的验收都包含它们。

1. **不动肌肉记忆。** 已有按钮的名字、位置、默认动作不变（规则 1）。新功能用"旁边多一个小入口"或"多一行状态"的方式加进去，不重排现有控件。
2. **当前状态写在界面上。** 凡是有模式或开关的地方，当前值直接显示成文字，不让用户靠记忆。例如「直接生成 · 不再确认」「素材：沿用 V4-10 · 1 的原片素材」。
3. **点了马上有反应。** 100 毫秒内出现按下或加载状态。超过 400 毫秒的操作显示转圈或进度。等待期间按钮不可重复点击。
4. **一件事只提示一次。** 同一次操作只弹一条提示；一次处理多项时合并成一条（"3 张大图已自动压缩"）。不连弹、不重复弹。
5. **能撤销。** 改动提示词、参考素材、排序的操作都进入现有撤销历史，`Ctrl+Z` 一次撤回一步；提示里写明"可按 Ctrl+Z 撤回"。
6. **不抢焦点、不跳动。** 打开浮层不改变提示词的滚动位置和面板高度（规则 11、39）；悬停不位移（规则 7）；浮层关闭后焦点回到原处。
7. **中文输入法安全。** 组字过程中不触发快捷键、不触发查找、不改写正文（规则 39）。
8. **提示颜色用对。** 完成用 `message.success`，中性说明用 `message.info`，警告用 `message.warning`，失败用 `message.error`（规则 49）。
9. **四套皮肤都能看清。** 只用主题变量，不写死颜色。暖樱粉、云母白、影视暗房、漫画分镜下逐个看过，文字和底色对比够。
10. **小窗口不挤坏。** Agent 侧栏最窄 320 像素、主窗口 1100 像素宽时，新控件可以换行或横向滚动，但不重叠、不截断关键文字。
11. **键盘走得通。** 新控件能用 Tab 走到，有 `aria-label`，`Esc` 关闭浮层。
12. **用用户的话。** 文案用原片素材、垫图、补洞、声线归属这些用户自己在用的词，不出现字段名、技术词。

**皮肤与窗口检查表**（每张带界面的实施单验收时都过一遍）

| 检查 | 通过标准 |
| --- | --- |
| 四套皮肤 | 新控件的文字、边框、选中态在每套皮肤下都清楚；影视暗房下没有白底刺眼的块 |
| Agent 侧栏 320 像素 | 回复卡片的按钮和状态行不重叠；可以换行 |
| 主窗口 1100 像素宽 | 提示词面板工具栏仍是一行，可横向滚动；新图标不把「开始创作」挤出可见区 |
| 悬停 | 没有位移，没有手型光标闪烁 |
| 键盘 | Tab 顺序合理；Esc 关闭；焦点可见 |
| 系统「减少动态效果」 | 新增的过渡动画停止或缩短 |
