## 用户要达到的结果

用户正在编辑一条视频提示词，想把里面所有的"餐厅"改成"咖啡店"。现在只能一处处手改，或者用顶部的批量替换——但那个是改整个文件夹里还没生成的视频组，不是只改手上这一条。

改完后：在提示词面板里按 `Ctrl+F`，输入"餐厅"，正文里所有"餐厅"都亮起来，显示共几处；填上"咖啡店"，点「全部替换」，一次换完；换错了按 `Ctrl+Z` 撤回。

## 现状（读 0.5.37 源码）

- 顶部已有「搜索 + 替换」：范围是当前文件夹或整个项目里**还没生成**的视频组，已生成和进行中的不改（`video/components/video-prompt-replace.tsx`、`video/prompt-replacement.ts`，规则 17、18）。本单不动它。
- 提示词输入框是自己实现的可编辑区（`video/components/prompt-reference-input.tsx`）：正文里的 @ 引用显示成不可编辑的小胶囊；有自己的撤销历史；标题、镜头、台词有高亮。里面没有查找功能。
- 把"正文第几个字"换算成"界面上的位置"的逻辑已经有（`video/prompt-locate.ts` 的 `locatePromptRange`，现在用于参考卡的「定位」）。

## 交互与界面

样子见 `设计预览/04-第1-2批界面.png`（设计预览，只说明摆法和操作，名称是占位）。

**1. 入口**

- 提示词面板底部工具栏右侧，在「清空输入」垃圾桶的**左边**加一个放大镜图标按钮，大小和旁边的图标按钮一致。悬停说明：`查找替换（Ctrl+F）`。
- 快捷键：光标在提示词面板里时，`Ctrl+F` 或 `Ctrl+H` 都打开查找替换条。面板外不响应，不影响别处。
- 只作用于视频提示词。音频区、图像区的输入框不在本次范围。

**2. 查找替换条**

位置：夹在参考素材条和提示词输入框**之间**的一行细条，高约 34 像素。

- 不盖住正文的任何一个字，所以不会出现"要找的那一处正好被查找条挡住"。
- 打开和关闭时，输入框里的正文一个像素都不动（面板是贴底浮动的，多出来的这一行往上长）；只有上面的参考素材条会上移或回落一行的高度。
- 面板高度的这点变化计入现有的底部留白计算（规则 11）。不在输入框内部加空白。

```
[查找…          ] Aa  2 / 7  ↑ ↓   [替换为…        ] [替换] [全部替换]            ✕
```

| 控件 | 作用 |
| --- | --- |
| 查找框 | 输入即查，正文里所有匹配处高亮 |
| `Aa` | 区分大小写，默认不区分。只对字母有意义 |
| `2 / 7` | 当前第几处 / 共几处。没有匹配时显示「无结果」，用次要文字色，输入框不变红、不抖动 |
| `↑` `↓` | 上一处 / 下一处，到头循环 |
| `✕` | 关闭 |
| 替换框 | 留空表示删除匹配的文字 |
| 「替换」 | 换掉当前这一处，然后自动跳到下一处 |
| 「全部替换」 | 一次换掉所有可替换的匹配处 |

一行放得下时就是一行。面板较窄放不下时折成两行：第一行查找，第二行替换；关闭按钮始终在最右。

**3. 键盘**

| 键 | 在查找框里 | 在替换框里 |
| --- | --- | --- |
| `Enter` | 下一处 | 替换当前这一处并跳到下一处 |
| `Shift+Enter` | 上一处 | 上一处 |
| `Tab` | 跳到替换框 | 跳到「替换」按钮 |
| `Esc` | 关闭 | 关闭 |

「全部替换」只能用鼠标点，不设快捷键，避免手滑一次改掉一整篇。

**4. 高亮与定位**

- 所有匹配处：浅黄色底。当前这一处：橙色底，更醒目。
- 跳到某一处时，正文自动滚到能看见它的位置，尽量在输入框中部；面板本身和页面不滚。
- 高亮只是视觉效果，不改动正文内容，不影响已有的标题、镜头、台词高亮和 @ 胶囊（规则 39）。
- 四套皮肤下高亮色都要和文字有足够对比；影视暗房下不用刺眼的亮黄。

**5. 打开和关闭**

- 打开时，如果正文里正选中着一段文字（不跨行、不超过 50 个字），自动填进查找框并把它当作当前这一处。否则沿用本次运行里上一次的查找词。
- 打开后焦点在查找框，内容全选，可以直接打字覆盖。
- 关闭时，光标回到正文里当前那一处并选中它，可以接着打字。高亮清除。
- 查找替换条开着的时候，照常可以点正文继续编辑；正文变了，匹配处和计数跟着更新。

**6. 替换的规则**

- **素材引用小胶囊里的字不替换。** 例如正文里有 @女主 胶囊，查"女主"时胶囊不计入总数、不高亮、不替换。计数后面跟一小段说明：`2 / 7 · 另有 2 处在素材引用里，不会替换`。这样不会把绑定搞坏。
- 替换等同于用户自己打字改：不触发自动重新匹配，现有的参考素材不动（规则 27）。改了角色名导致对不上素材时，照常出现现有的虚线「待补素材」提示。
- 正文里的时长被改动时，现有的"正文时长和生成秒数不一致，点此同步"提示照常出现（规则 21）。
- 「全部替换」算**一步**撤销。「替换」每次算一步。`Ctrl+Z` 撤回、`Ctrl+Y` 重做，走现有的撤销历史。
- 全部替换后弹一条：`已替换 5 处，可按 Ctrl+Z 撤回`。条保持打开，计数更新（通常变成"无结果"）。
- 查找框为空时，两个替换按钮不可点。

**7. 中文输入法**

- 在查找框里用输入法组字的过程中，不更新查找结果；上屏之后再查。
- 在正文里组字的过程中，不重算高亮。

**8. 和已生成视频的关系**

对一条已生成的视频点「重新编辑」后，编辑框里是它的提示词副本，查找替换改的是这份副本，提交后成为新的一版。历史视频自己的提示词不会被改写，和规则 18 的原则一致。

**空状态**：正文为空时，放大镜按钮可点，条里显示「无结果」。

## 数据与旧项目

不新增、不修改任何持久化数据。查找词和替换词只在本次运行的内存里记着，不写入磁盘。

## 改动范围

| 文件 / 函数 | 负责什么 | 要做什么 |
| --- | --- | --- |
| 新增 `video/prompt-find.ts`（建议名） | 纯计算 | 两个函数：给定正文、查找词、是否区分大小写、胶囊所占的范围，返回可替换的匹配处列表和"落在胶囊里的处数"；给定匹配处和替换词，返回新的正文和光标位置 |

| `video/prompt-locate.ts` · `locatePromptRange` | 正文位置 → 界面位置 | 把其中换算位置的部分抽出来，供画高亮复用。现有的「定位」行为不变 |
| `video/page.tsx` · 提示词面板底部工具栏（带 `data-video-generation-toolbar` 的那一行） | 清空、收起、重新匹配、开始创作等按钮 | 垃圾桶左边加放大镜按钮；注册 `Ctrl+F`、`Ctrl+H`，仅在 `[data-video-composer]` 内生效 |

**关于高亮怎么画（给本机的建议，可自行选择）**

推荐用浏览器的"自定义高亮"能力：把匹配处登记成高亮范围，用样式上色。它不往正文里插入任何标签，所以不会动到光标、输入法、胶囊和撤销历史，这正是规则 39 最怕被破坏的几样东西。Electron 31 的内核版本应当支持，请本机先确认。

如果不支持，退一步：只把"当前这一处"用选区标出来，其余靠计数和上下跳转，不要为了画全部高亮去改写正文的结构。

说明：带 `data-video-generation-toolbar` 的那一行工具栏出现在即梦 CLI、小云雀、Oii 这几种渠道的布局里，也就是用户日常用的布局。其他渠道的面板底部是另一种网格布局，那里不强求放图标，但 `Ctrl+F`、`Ctrl+H` 要同样可用。

不改：`video/components/video-prompt-replace.tsx`、`video/prompt-replacement.ts`（顶部批量替换）；`matchPromptAssets`；自动匹配的触发时机。

## 验收

准备：一条较长的提示词，里面有 3 处"餐厅"，其中一处在某个 @ 胶囊的名字里（例如素材名是"餐厅-夜"）。

| 操作 | 应该看到 |
| --- | --- |
| 光标在提示词里，按 `Ctrl+F` | 条出现在参考素材条和输入框之间；输入框里的正文位置没有任何变化；没有字被盖住；焦点在查找框 |
| 输入"餐厅" | 2 处亮起，计数 `1 / 2`，后面跟着「另有 1 处在素材引用里，不会替换」 |
| 按 `Enter` 两次 | 跳到第 2 处，再回到第 1 处；正文自动滚到看得见的位置 |
| 替换框填"咖啡店"，点「替换」 | 当前这一处被换掉，自动跳到下一处，计数变 `1 / 1` |
| `Ctrl+Z` | 刚才那一处恢复成"餐厅" |
| 点「全部替换」 | 2 处都换掉；提示「已替换 2 处，可按 Ctrl+Z 撤回」；胶囊还是"餐厅-夜"，没被改 |
| `Ctrl+Z` 一次 | 2 处同时恢复 |
| 查一个不存在的词 | 显示「无结果」；替换按钮不可点；输入框不变红 |
| 在正文里选中"女主"两个字，再按 `Ctrl+F` | 查找框里已经是"女主"，且当前这一处就是选中的那处 |
| 按 `Esc` | 条关闭，高亮消失，光标在正文里刚才那一处 |
| 用中文输入法在查找框里打"can ting"还没上屏 | 计数不跳动；上屏后才更新 |
| 条开着，直接在正文里打字 | 正常输入；匹配处和计数跟着变 |
| 把"女主"全部替换成"女一"（参考区挂着"女主"的图） | 参考区的图没被移除也没被替换；对不上的名字出现现有的待补提示 |
| 光标在 Agent 输入框里按 `Ctrl+F` | 没有反应，不弹这个条 |
| 对已生成的视频点「重新编辑」，在编辑框里全部替换，不提交，再打开这条视频的详情 | 详情里的原提示词没有变 |
| 顶部的批量搜索替换 | 和改之前一样 |
| 一条 5000 字的提示词里查一个出现 200 次的字 | 输入不卡，滚动不卡 |
| 长提示词打字、粘贴、拖选、撤销重做（规则 39 的各项） | 和改之前一样，不丢字、不跳光标、不闪 |
| 四套皮肤；面板拉到最窄 | 条的文字和高亮都清楚；窄时折成两行，不超出面板、不挤掉关闭按钮 |
| 条开着时滚动视频列表到最后一排 | 最后一排仍能滚到面板上方看全（底部留白跟着面板高度变了） |

相关的已有测试入口：`desktop-app/test-prompt-reference-chip-dom.mjs`、`test-mention-anchor-residue.mjs`、`test-dialogue-highlight.mjs`、`test-reference-removal-undo.mjs`、`test-video-prompt-replacement.mjs`、`test-video-prompt-replacement-ui.mjs`。改动后运行，确认胶囊、高亮、撤销和批量替换没被带坏。建议给第 1 步的纯计算函数加用例——风险是以后调整胶囊范围的算法时，替换悄悄改到了素材引用。

## 规则更新

用户体验通过后修改 `工作台功能保留规则.md`。**第 17、18 条原文不动**，在第 18 条之后新增一句（并入第 18 条末尾或单列均可）：

> 提示词面板内另有"查找替换"（放大镜图标或 Ctrl+F / Ctrl+H）：只作用于当前编辑框里的这一条提示词，支持逐处替换与全部替换，素材引用小胶囊内的文字不替换，全部替换算一步撤销，不触发自动重新匹配；它改的是编辑框内容，不改写已生成视频的历史提示词。顶部按文件夹的批量替换不受影响。
