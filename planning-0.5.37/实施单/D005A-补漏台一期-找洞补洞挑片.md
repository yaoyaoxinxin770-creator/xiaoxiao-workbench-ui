## 用户要达到的结果

用户现在补漏的做法：把一集的视频拖进剪映拼起来连着看，找两类问题——某个镜头本身不行，或者上一段结尾和下一段开头接不上（最常见是站位）。发现问题后回工作台，从上一段里导出一帧当垫图，重新生成，再拖回剪映对比。候选多了以后分不清哪条是补哪个洞的、哪条定了。

做完这一期，这些都在工作台里完成：

1. 切到「补漏台」，点「连播」，一集的视频按顺序连着放，不用拼进剪映。
2. 看到问题按 `X` 记一笔（哪一组、哪个镜头，或者哪两段之间接不上），可以顺手停在一帧上按 `G` 定垫图。
3. 在待补清单里点「去补这个洞」：提示词面板展开，载入这一组的原片素材，垫图自动截好挂上，这次生成的视频自动标成补洞版本。
4. 候选出来后点「上下文试播」：上一段最后 2 秒 → 候选 → 下一段开头 2 秒。`[` `]` 换候选对比，满意的按 `F` 采用，这个洞就算补上了。
5. 没用的按 `D` 标废片。

已确认：做成视频页里的一个视图，不是独立页面；放映区和时间线始终深色；补漏视频两种落法都支持。

### 3. 时间线

**放哪些、按什么顺序**

- 范围是当前文件夹（遵守现有的"包含子文件夹"开关）。选的是「全部视频」时也能用，但顶上提示一行 `选一个剧集文件夹，连播的顺序才是一集的顺序`。
- 一组一格，不管这组有几个版本。
- 默认顺序是编号顺序，和网格里「名称（编号顺序）」完全一样。
- 可以把一格拖到别的位置。拖过以后，这个文件夹的时间线按拖的结果记住，和网格的排序互不影响。新导入的组按编号插到它的前一个邻居后面。右键时间线空白处有「恢复编号顺序」。
- 右键某一格 →「不进连播」：这一格变成半透明并带一个小斜纹角，连播和只看接缝时跳过它。用途是备选版本、测试片。再点一次恢复。

**每一格显示什么**

| 情况 | 样子 |
| --- | --- |
| 有可播的版本 | 采用版的封面、左上角编号、右下角时长。宽度按时长，64 到 160 像素之间 |
| 还没生成 | 虚线框，写「没生成」，固定 84 像素 |
| 正在生成，还没有可播的版本 | 虚线框里显示进度 |
| 有待补的洞 | 右上角一枚「待补」小标 |
| 有还没定的补洞候选 | 右上角蓝色「补洞 3」（数字是候选条数） |
| 整组都是补洞阶段生成的（另起编号的过渡片） | 蓝色边框 |
| 当前正在看的 | 红色粗边框，时间线自动滚到它 |
| 采用版的文件不在本机，或只能去官网看 | 灰底，写「不在本机」，连播时跳过 |

**接缝**：相邻两格之间一个小菱形。灰色是没标记；红色是有没解决的衔接问题；黄色是"先凑合"；绿色是已解决。点菱形等于在只看接缝模式下跳到这个接缝。

时间线上方一行小字：`16 组 · 采用版合计 02:41 · 还有 2 组没生成`。

封面用现有的取封面办法（`video/video-poster.ts`），只加载可见范围和左右各一屏（规则 40）。

### 4. 放映区

**连播**

- 点「▶ 连播」或按 `空格`：从当前这一格开始，按时间线顺序连着放每一格的**采用版**。没生成的、不进连播的、不在本机的跳过。
- 放到哪一格，时间线、右侧面板、镜头条都跟着切到那一格。
- 两段之间不应该有看得见的停顿：提前把下一段准备好，上一段放完立刻接上。
- 放完最后一格停住。
- 声音正常播放。浏览器拦截自动出声时沿用现有的处理（先静音播放并提示）。

**镜头条**：画面下面一条，按提示词里的镜头时间段分格（复用视频详情里现有的分镜进度条，`page.tsx` 的 `parseVideoShotSegments`）。点一格跳到那个镜头。提示词里没写镜头的只显示一条普通进度条。

**播放控制**：`上一帧` `下一帧` `倍速` `设为垫图帧` `上一版` `下一版`，以及当前时间 / 总时长。逐帧和倍速沿用视频详情里现有的做法（`video-frame-capture.tsx`）。「截音频」属于 D009，本单不加。

**只看接缝**

- 点「只看接缝」或按 `S` 进入。这时每次只放一个接缝：上一段的最后 N 秒，紧接着下一段的开头 N 秒，放完停住。
- N 默认 2 秒，按钮上的小下拉可以选 1、2、3 秒，记住选择。
- `→` 下一个接缝，`←` 上一个接缝，`空格` 重放当前接缝。
- 画面上方一行字说明现在放的是什么：`接缝：V4-09 末 2 秒 → V4-10 首 2 秒`。
- 再按 `S` 退出，停在当前这一格。

**上下文试播**（挑候选时用）

- 右侧版本条里选中某个版本后，点「上下文试播」：上一段最后 2 秒 → 这个版本从头到尾 → 下一段开头 2 秒。上一段和下一段用的是它们各自的采用版。
- `[` `]` 换到本组上一个 / 下一个版本，并且**从同一个起点重新放**，方便反复对比。
- 画面上方一行字：`上下文试播：V4-09 末 2 秒 → 本段 v3 → V4-11 首 2 秒`。
- 这一组是时间线第一格或最后一格时，缺的那一头不放。

### 5. 右侧：当前视频

从上到下：

1. **标题行**：`V4-10`、`正在看 v3 · 补洞`、`5 个版本`。
2. **版本条**：这一组全部记录的小缩略图，一排，可横向滚动。每张下面一个小标签：
   - `v1 采用`（绿）、`v2 废片`（灰，缩略图半透明）、`v3 补洞`（蓝）、`v5 生成中 38%`、`v6 失败`。
   - 版本号就是网格角标里「V4-10 · 3」的那个 3，两边保持一致。
   - 点一张就在放映区看它。正在看的那张有红色边框。
3. **标记按钮**：`采用 F`、`废片 D`、`待补 X`。按钮上直接显示快捷键。当前状态用按下的样子表示。
4. **本组未采用的 → 全部标废片**：一个小按钮。点了以后提示 `已把 3 条标为废片　撤销`，「撤销」恢复它们原来的状态。生成中和失败的记录不算在内。
5. **备注**：就是这条视频现有的备注（和网格、详情里是同一份）。
6. **这个洞**：当前这一组有待补的洞时显示，见下面第 7 节。
7. **打开详情**：一个小链接，打开现有的视频详情弹窗。

### 6. 左侧：清单

三个页签，页签上带数量。

**待补**（补漏的工作单）

每个洞一张小卡：

```
[衔接] V4-09 → V4-10
站位：女主应在男主左侧
候选 3 · 垫图已选
```

- 类型标签：`镜头` 或 `衔接`。
- 标题：`V4-12 · 镜头 03`，或 `V4-09 → V4-10`。
- 备注（没写就不显示这一行）。
- 状态：`还没补` / `垫图已选` / `候选 1 · 生成中 38%` / `候选 3` / `先凑合用 v2`。
- 点卡片：跳到这个洞所在的位置（镜头类跳到那一组那个镜头；衔接类进入只看接缝并停在这个接缝），右侧显示「这个洞」。
- 卡片右上角小菜单：`改成先凑合`、`标为已解决`、`删除这条标记`。
- 清单最下面折叠一行 `已解决 4　展开`。

**废片**

- 列出当前范围里所有废片（灰底的，或标了红色「× 不可用」的，不含已进回收站的）。每行：缩略图、`V4-10 · 2`、原因（灰底 / 不可用）、备注。
- 每行一个「取消废片」。
- 底部保留现有的「一键将废片移入回收站 (N)」，行为不变。

**全部**

- 按时间线顺序列出每一组一行：编号、采用的是哪一版、有几个洞、有几条废片。点一行跳到那一组。相当于一张镜头表。

空状态：待补为空时写 `还没有标记。连播时看到问题按 X`；废片为空时写 `这个文件夹里没有废片`。

### 7. 标记待补、定垫图

**按 `X`（或点「待补」）**

| 当时在做什么 | 记成什么 |
| --- | --- |
| 普通播放或暂停，提示词里有镜头时间段 | 镜头类：`V4-12 · 镜头 03`（当前时间落在哪个镜头） |
| 普通播放或暂停，提示词里没有镜头 | 镜头类：`V4-12 · 00:03.5` |
| 只看接缝 | 衔接类：`V4-09 → V4-10` |

- 记下以后，右侧「这个洞」里的备注框自动获得焦点，可以直接打两个字；按 `Enter` 保存并把焦点还给放映区，按 `Esc` 不写备注直接回去（洞已经记下了）。输入法组字过程中的回车不算保存。
- 连播不会因为按 `X` 停下来，除非开始打备注。
- 同一个位置已经有没解决的洞时，再按 `X` 不新增，只是选中它。

**右侧「这个洞」**

```
这个洞　　衔接 · V4-09 → V4-10
[备注：站位：女主应在男主左侧        ]
垫图　[缩略图] V4-09-帧-00m07s12
      取自上一段你暂停的那一帧　　换一帧
[去补这个洞 ▾]  [发给 Agent]
会载入 V4-10 · 1 的原片素材，挂上垫图，并自动标成补洞版本。
```

**定垫图（按 `G` 或点「设为垫图帧」）**

- 把放映区当前停住的这一帧记为"当前选中的洞"的垫图。可以是任何一组的任何一帧，最常见是上一段里能看清站位的那一帧。
- 这时只是记下"哪条视频的第几秒"，不截图、不进资产库。
- 没有选中任何洞时，提示 `先按 X 记一个洞，或在左边点一个洞`。
- 衔接类的洞没定垫图时，默认用上一段采用版的最后一帧，卡片上写 `垫图：上一段最后一帧（默认）`。镜头类的洞默认没有垫图。
- 「换一帧」：跳到垫图所在的那条视频那个时间点，方便重新选。

### 8. 去补这个洞

点「去补这个洞」后依次发生：

1. 提示词面板展开。
2. 载入目标视频组的提示词和**原片素材**，原片取这一组的采用版。做法和点这条视频的「重新编辑」一样（D003A、D006 已经把这段逻辑整理好）。编辑区里有没提交的内容时，沿用现有切组时的保存和提醒方式，不新增弹窗。
3. 有垫图的话：把那一帧截下来存进资产库（和现有「保存到资产库」同一个办法、同一种命名，如 `V4-09-帧-00m07s12`；同一帧已经存过就直接用，不重复存），加为**普通参考图**（不放首帧，D006 的约定）。
4. 提示词面板里出现一行状态（约定 2：当前状态写在界面上）：

   ```
   正在补洞：V4-09 → V4-10 衔接 · 垫图 V4-09-帧-00m07s12　　退出补洞
   ```

5. 在这个状态下提交的视频，生成记录自动带上现有的「补洞阶段」标记，**不需要、也不会去拨工具栏上的「补漏洞」开关**。
6. 像平常一样生成。生成中可以继续看片、去补别的洞，不用等。
7. 载入别的组、清空编辑区、点「退出补洞」，这个状态结束。之后的提交是否标补洞，回到由工具栏开关决定。

**补到哪一组**（按钮右边的小下拉）

| 洞的类型 | 可选 | 默认 |
| --- | --- | --- |
| 镜头类 | 补这一组 | 补这一组 |
| 衔接类 | 补下一段（V4-10）／补上一段（V4-09）／新建一段过渡片 | 补下一段 |

- 补这一组、补上一段、补下一段：新视频成为那一组的新版本（`V4-10 · 2`），归属沿用原组（规则 20、37）。
- **新建一段过渡片**：先问编号，输入框里预填 `上一段编号-1`（已被占用就 `-2`、`-3`），可以改。确定后在同一个文件夹里新建一个空的视频组，时间线上插在这两段中间；编辑区切到这个新组，挂上垫图，提示词由用户自己写或粘贴。之后生成的视频归到这个新组。新组可以用现有的「删除视频组」删掉。
- 用户上次选的补法会被这个洞记住，下次点按钮直接用。

**发给 Agent**：把目标视频发给 Agent（和网格里「发给 Agent」同一条路），同时带上垫图这一帧（和现有「截取当前帧发给 Agent」同一条路），输入框里预填 `补洞：V4-09 → V4-10 衔接。站位：女主应在男主左侧`，不自动发送。Agent 改完回填时按 D006 的规则走。

**候选**：这个洞的候选 = 目标组里、在这个洞记下之后生成的、带补洞标记的版本。不用单独登记。

### 9. 采用和废片的规则

**采用（`F`）**

- 每组最多一个采用版。对另一个版本按 `F`，采用就换过去；对已经采用的版本再按 `F` 是取消。
- 没有手动采用过的组，自动取"最新一条成功、不是废片、**不是补洞阶段**的版本"。也就是说，补洞候选在按 `F` 之前不会自己顶掉原片。整组都是补洞版本时（过渡片），取最新一条成功、不是废片的。
- 采用版被标成废片、被移进回收站或被删除后，这一组回到自动规则。
- 对一个候选按 `F`：这个洞自动标为已解决，时间线这一格换成它，提示 `已采用 v3，「V4-09 → V4-10 衔接」已解决　撤销`。
- 都不满意、先挑一条凑合：对它按 `F`，然后在洞的小菜单里选「改成先凑合」。洞留在待补清单里，状态写 `先凑合用 v3`，时间线上是黄色。

**废片（`D`）**

- 就是现有的「蒙上灰底（废片）」，同一个字段。在补漏台标的，网格和详情里同样是灰底；反过来也一样。
- 红色「× 不可用」颜色标记照旧算废片，本单不改它。

**和现有标记的关系**

- 审片状态（无状态 / 进行中 / 待审 / 已通过 / 已拒绝）、颜色、备注、收藏、序号标红：全部保留，含义不变，补漏台不读也不写审片状态。
- 「补洞阶段」蓝框标记：沿用。工具栏上的「补漏洞」开关、右键「加入补视频漏洞阶段」、「仅看补漏洞阶段视频」筛选都不改。

### 10. 快捷键

只在补漏台视图里、光标不在任何输入框和提示词编辑区里、没有弹窗打开时生效。输入法组字过程中不触发。

| 键 | 作用 | 键 | 作用 |
| --- | --- | --- | --- |
| `空格` | 播放 / 暂停 | `F` | 采用 / 取消采用当前版本 |
| `←` `→` | 上一帧 / 下一帧；只看接缝时是上一个 / 下一个接缝 | `D` | 废片 / 取消废片 |
| `↑` `↓` | 上一组 / 下一组 | `X` | 标记待补 |
| `[` `]` | 本组上一版 / 下一版 | `G` | 把当前帧设为垫图 |
| `S` | 只看接缝 开 / 关 | | |

- 不占用 `Esc`（现有的防卡解冻）和 `Ctrl+Z`（现有的撤回导入、提示词撤销），带 `Ctrl` `Alt` 的组合键一律不拦。
- 视频详情弹窗打开时，弹窗里现有的左右键（上一个 / 下一个视频）照旧，补漏台的快捷键不生效。
- 顶上那一条的最右边放一个小问号，悬停显示这张表。

### 11. 提示和撤销

- 标记类操作（采用、废片、待补、设垫图）不弹成功提示，界面上的状态变化就是反馈。只有"连带改了别的东西"时提示一次，并带「撤销」：采用候选连带解决了洞；全部标废片。
- 删除一条待补标记：提示 `已删除标记　撤销`。
- 拖动时间线顺序：不提示，右键「恢复编号顺序」可以整体还原。
- 新建过渡片：提示 `已新建视频组 V4-09-1`（`message.success`）。
- 去补这个洞时垫图截取失败（视频文件不在本机等）：`message.warning` 说明原因，其余步骤照常完成，垫图位置显示「没截到，换一帧」。

## 数据与旧项目

全部存在本机现有的视频项目数据里（`stores/use-video-studio-store.ts`，IndexedDB `video_studio`）。新增的都是可选内容，旧项目没有它们就等于"没标"。

| 新增 | 放在哪 | 内容 | 说明 |
| --- | --- | --- | --- |
| 采用版 | 视频组上一个可选字段 | 被采用的那条记录的编号 | 没有就走自动规则 |
| 不进连播 | 视频组上一个可选开关 | 是 / 否 | D012 以后会用它表示"备选版本" |
| 待补清单 | 按项目存的一个新列表 | 每条：类型（镜头 / 衔接）、所在视频组、衔接类还有上一段的视频组、标记时在看的那条记录、镜号或时间、备注、垫图（哪条记录的第几秒）、垫图入库后的资产编号、补到哪一组、状态（待补 / 先凑合 / 已解决）、记下的时间、解决的时间和用的哪一版 | 候选不存，按规则现算 |
| 时间线顺序 | 按项目、按文件夹存的一个新列表 | 视频组编号的顺序 | 没有就是编号顺序 |
| 视图 | 现有的项目视图状态里 | 当前视图（网格 / 补漏台 / 分镜对照）、接缝秒数、左清单当前页签 | 见下面的提醒 |
| 废片、补洞阶段、备注 | 现有字段 | — | 不新增 |

- **提醒**：`video-studio.tsx` 里保存项目视图状态的那一段，每次都是用当前界面状态整份重建后存进去的。新加的视图字段必须加进重建的清单，否则会被它覆盖掉。待补清单和时间线顺序不要放进视图状态，单独放。
- 新列表要加进持久化的清单（`partialize`），否则重启就没了。
- 待补清单里不存文件夹：一个洞属于哪个文件夹，由它的视频组现在在哪决定。视频组被移到别的文件夹，洞跟着走。
- 视频组被删除（进了"已移除"）：它的洞不显示；恢复视频组后洞回来。项目被删除：这个项目的待补清单和时间线顺序一起清掉。
- 衔接类的洞记的是"上一段、下一段"两个组。时间线顺序变了、这两组不再相邻时，清单里照常显示，时间线上不画红菱形，卡片上加一句 `这两段现在不相邻`。
- 生成记录本身不改结构。补洞标记用现有的 `patchStage`。
- 归属、任务身份、恢复和重试：不改（规则 20、37、45）。补漏台里的提交和网格里载入同一组后的提交走同一条路。
- 备份（规则 4）：实施前备份工作台数据目录，包含 `video_studio`。
- 回退：装回旧版后，带新字段的项目能正常打开；旧版不认识这些字段，不显示也不报错。请本机验收时确认。旧版运行期间保存数据，是否会把新增的顶层列表丢掉，也请本机确认并写进报告。

## 规则更新

用户体验通过后，在 `工作台功能保留规则.md` 新增一条（编号接在现有最后一条后面）：

> **补漏台视图。** 视频页工具栏提供「网格 / 补漏台 / 分镜对照」视图切换，三个视图共用同一个项目、文件夹、底部提示词面板和 Agent 侧栏，切换时保留当前视频组，工具栏原有按钮不因视图变化而移动或消失。补漏台的放映区和时间线始终为深色，其余部分跟随皮肤。时间线一组一格，默认按编号顺序，可拖动调整并按文件夹记住，可把某一组设为「不进连播」。每组最多一个「采用」版本；未手动采用时取最新一条成功、非废片、非补洞阶段的版本，补洞候选须经用户采用才进入连播。「待补」标记分镜头类与衔接类，可记备注和垫图帧；从待补标记「去补这个洞」时载入目标组采用版的原片素材、把垫图加为普通参考图，期间提交的视频自动带补洞阶段标记，不改变工具栏「补漏洞」开关的状态，归属沿用目标视频组。废片沿用灰底与「× 不可用」，审片状态、颜色、备注、收藏的含义不变。补漏台的快捷键只在该视图内、焦点不在输入区时生效，不占用 `Esc` 与 `Ctrl+Z`。

> 从补漏台的待补标记发起的生成，自动带补洞阶段标记，与工具栏开关的状态无关。
