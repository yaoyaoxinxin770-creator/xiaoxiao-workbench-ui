## 用户要达到的结果

用户写好分镜稿后会导入工作台生成视频。审片时想对着剧本原文看"演得对不对、台词有没有改、有没有漏拍的戏"，现在只能另开一个文档来回找。

做完以后：

1. 切到「分镜对照」，点「导入剧本」，把剧本拖进去。工作台按分镜表头里写的场次（`剧本4-4`）和台词，自动把剧本的每一行分给对应的视频组。
2. 每个视频组一行三栏：左边是成片，中间是这一组的分镜提示词，右边是这一组对应的剧本原文。
3. 剧本每行左边一个小点，一眼看出：台词和剧本一字不差、画面内容对得上、只是按位置归进来的、台词和剧本不一样。
4. 同一场戏写了两个版本时，选「成片用第 1 版」还是「第 2 版」。没选的那一版留着当备选，不进连播。
5. 剧本里有、分镜里还没有的场次，显示成「缺分镜」。

已确认：这页先用来对照，生成仍然用底部提示词面板；剧本整个项目一份，只存在本机。

## 交互与界面

样子见 `设计预览/08-分镜对照.png`（用的是 `样例/` 里那份编造的稿子）和 `设计预览/07-弹层.png` 里的「导入剧本」弹窗。都是设计预览，文字不一致时以本单为准。

### 1. 入口和整体

- 视图切换的第三段「分镜对照」（切换钮是 D005A 加的）。
- 和网格、补漏台看的是同一个项目、同一个文件夹。切视图时保留当前视频组。
- 工具栏原有按钮不动。底部提示词面板和 Agent 侧栏照常可用，进入时提示词面板收成一条。
- 整页跟随当前皮肤（不像补漏台那样用深色）。

```
┌ 自己的一条：[导入分镜] [导入剧本]   6 组对上 · 1 组未对上   台词 10 句 · 一致 9 · 不一致 1   其余 15 行 · 对上 14 · 靠位置 1   [人名对应 2 个] ┐
├────────┬───────────────────────────────────────────────────────────────┤
│ 场次目录 │ 成片          分镜（视频提示词）                    剧本原文   ● 台词原文一致  ○ 画面对得上  ◌ 靠位置  │
│ 9-1     │ ── 9-1 日/内 咖啡店 · 6 组 · 剧本 14 行 · 覆盖 100% ──────── 成片用 [第 1 版｜第 2 版]            │
│  第 1 版 │ [第 1 版  V9-01、V9-02                                              成片用这一版]             │
│  第 2 版 │ ┌ [成片]   【视频编号V9-01｜…】                      ○ △ 门上的风铃响了一声。            ┐   │
│  两版共用│ │ 载入并创作 总时长… 【镜头01】…                      ○ △ 林夏推门进来，四处张望。        │   │
│  跨到9-2 │ └          镜头 03 【男主】 你来了。                 ● 周野（抬头）说："你来了。"        ┘   │
│ 9-2     │ …                                                                                      │
│ 9-3 缺分镜│                                                                                        │
└────────┴───────────────────────────────────────────────────────────────┘
```

- 场次目录约 200 像素；三栏是：成片 200 像素、分镜自适应、剧本最宽 430 像素。
- 主窗口 1100 像素宽或开着 Agent 侧栏时：场次目录收成顶上的一个下拉；剧本栏缩到 320 像素；成片栏缩到 160 像素。不重叠、不截断关键文字。
- 还没导入剧本时：照常列出每个视频组的成片和分镜，右栏是一块虚线提示 `还没有剧本。点「导入剧本」`。

### 2. 每个视频组一行

**左：成片**

- 显示这一组的采用版（D005A 的规则）。悬停播放，和网格卡片一样；点一下打开现有的视频详情弹窗。
- 下面一排小圆点，一个版本一个点，点了换看哪一版（只是换着看，不改采用）。
- 两个小按钮：`✔ 采用`、`✖ 废片`，和补漏台里是同一份标记。装了 D005B 的话再加 `★ 高光`。
- 还没生成：虚线框写「还没生成」，下面一个按钮「载入并创作」——载入这一组并展开提示词面板，就是现有的载入本组。
- 最下面一行小字：`23.4 秒 · 8 镜`。

**中：分镜**

- 这一组的提示词，带现有的高亮（标题、镜头、台词）。默认折叠：表头、总时长、承接行、前三个镜头的第一行、这一组的台词。点「展开全文（共 8 镜）」看全部。
- 台词前面一个小标 `镜头 03`，说明这句在第几个镜头。
- 下面一排小标签：这一组用到的人物、场景、道具、音频（取这一组记录过的素材）。
- 两个按钮：`重新编辑`、`发给 Agent`，就是网格里的同名动作。

**右：剧本**

这一组对应的剧本原文，一行一条，保持剧本里的顺序。每行左边一个小点：

| 小点 | 意思 | 什么时候是这样 |
| --- | --- | --- |
| 实心绿 | 台词原文一致 | 剧本这句台词在分镜里找到了，去掉标点和空格后一字不差 |
| 实心绿 + 蓝色小标 `拆成 2 镜 · 镜头 02、03` | 同上 | 一句台词被拆在相邻两个镜头里，拼起来一字不差 |
| 实心黄 | 台词不一致 | 找到了很像的一句，但不完全一样 |
| 空心绿 | 画面对得上 | 动作或描写行，和这一组某个镜头的画面文字相近 |
| 虚线灰 + 灰色小标 `靠位置` | 按前后位置归进来的 | 内容没对上，只是夹在这一组的两句台词之间，或紧挨着这一组 |
| 蓝色小标 `手动` | 用户自己指定的 | 见下面第 5 节 |

- 一组跨两场时（表头写着 `剧本9-1…结尾＋9-2…开头`），剧本栏中间插一行场次分隔：`9-2　日/外　咖啡店门口`。
- **点剧本的一行**：这一行高亮；中间的分镜栏自动展开到对应的镜头，对应的台词或镜头行加一圈描边。**点分镜里的一句台词**：右边对应的剧本行高亮。再点一次或点别处取消。
- **点黄色的行**：弹出一个小浮层，上下并排显示「剧本：……」「分镜：……」，不同的字标出来。三个按钮：
  - `复制剧本原句`
  - `载入并定位到这句`：载入这一组，展开提示词面板，把光标定位到这句台词（用现有的提示词定位）。改不改由用户自己决定，本单不自动改提示词。
  - `标为没问题`：这一行变成实心绿加小标 `已确认`，以后不再提醒。

**全部展开 / 全部收起**：自己那一条的右侧有一个小开关。收起时每组只占一行：编号、表头、`23.4 秒 · 8 镜`、`剧本 6 行 · 台词 2 句全对上`，点一行展开它。默认展开。

### 3. 按场次分段

- 每一场一个标题行：`9-1　日/内　咖啡店 · 6 组 · 剧本 14 行 · 覆盖 100%`。
- **覆盖**：这一场里（成片用的那一版加上两版共用的部分）已经分给某个视频组的剧本行，占这一场全部行的比例。
- 这一场下面没分出去的行，集中列在这一场最后：`未分配 3 行`，展开可以看、可以手动归组。
- **缺分镜**：剧本里有、没有任何视频组对上的场次，显示成一行虚线占位，写「这一场还没有分镜」，右栏照常列出剧本原文，左边一个按钮「导入分镜」。
- **未对上剧本**：表头里没写场次、或者写的场次剧本里没有的视频组，集中放在最下面一段「未对上剧本 N 组」。每行右栏写 `没找到对应的场次`，旁边一个下拉「指定场次」，选了以后这一组归到那一场，并重新对一遍它的行。
- 左侧场次目录：每场一行，有编号、场景名、组数和覆盖条；有多个版本的场次下面缩进列出 `第 1 版`、`第 2 版`、`两版共用`、`跨到 9-2`；缺分镜的场次带一个小标；最下面是「未对上剧本」。点哪行滚到哪。

### 4. 一场戏多个版本

- 这一场的剧本里有 `【第1版】…【第1版结束】`、`【第2版】…` 这样的块时，标题行右边出现：`这一场有两个版本，成片用 [第 1 版｜第 2 版]`，后面一句小字 `连播和补漏台的时间线按选中的走`。默认第 1 版。
- 第一次对上一个有多个版本的场次时，默认选择立刻生效：其他版本的视频组设为「不进连播」，并提示一次 `9-1 有两个版本，成片先按第 1 版；V9-B1、V9-B2 设为备选，不进连播`。否则连播会把两个版本都放一遍。
- 下面按块分段，每段一个小标题条：
  - `第 1 版　V9-01、V9-02　　成片用这一版`
  - `第 2 版　V9-B1、V9-B2　　备选，不进连播`
  - `两版共用　V9-03`
  - `跨两场　V9-04　这一组前半是 9-1 的结尾，后半是 9-2 的开头`
- 换一个版本后：
  1. 新选中那一版的视频组取消「不进连播」，其他版本的视频组设为「不进连播」（D005A 的开关）。两版共用的组不动。
  2. 覆盖按新选中的那一版重算。
  3. 提示一次（`message.success`）：`9-1 成片改用第 2 版：V9-B1、V9-B2 进连播，V9-01、V9-02 设为备选　撤销`。
- **时间线默认顺序的补充规则**（改 D005A 里"默认顺序"的算法，不改用户拖过的顺序）：
  - 先按编号顺序排好；
  - 对每个有多个版本的场次：把这一场所有带版本的组取出来，排成"成片用的那一版在前、备选的在后、各自按编号"，整体插回到这一场第一个「两版共用」的组前面；这一场没有共用的组时，插回到这些组里编号最小者原来的位置。
  - 例：编号顺序是 `V9-01 V9-02 V9-03 V9-04 V9-B1 V9-B2`。成片用第 2 版时，默认顺序变成 `V9-B1 V9-B2 V9-01 V9-02 V9-03 V9-04`，连播实际放的是 `V9-B1 V9-B2 V9-03 V9-04`。
  - 补漏台里「恢复编号顺序」这个菜单项改名为「恢复默认顺序」，恢复的就是这个结果。

### 5. 手动改归属

自动对应不可能全对，所以每一行都能手动改：

- 鼠标移到剧本行上，行首出现一个勾选框；勾一行或多行（可以按住 `Shift` 连选）。
- 勾了以后剧本栏底部浮出一小条：`已选 3 行　归到 [V9-03 ▾]　设为未分配　取消`。下拉里列出这一场的视频组。
- 改过的行带蓝色小标 `手动`。**重新导入剧本或重新对齐时，手动改过的行不被覆盖**（只要这一行的文字没变）。
- 行的小菜单里有「恢复自动」：去掉手动标记，按自动结果重新归。
- 这些操作提示一次并带「撤销」：`已把 3 行归到 V9-03　撤销`。

### 6. 导入

**导入分镜**：打开现有的「导入视频组」弹窗，行为完全不变。导入完成后，如果已经有剧本，自动对新导入的组做一次对应。

**导入剧本**（新弹窗）

```
导入剧本                                                  剧本只保存在本机
┌───────────────────────────────┐
│  把剧本拖到这里，也可以直接粘贴文字    │   [选择文件]   支持 .md .txt .docx
└───────────────────────────────┘
已选：第 9 集 剧本.docx

识别预览　3 场 · 28 行 · 已对上 6 组
9-1  咖啡店 日/内        20 行   对上 6 组
9-2  咖啡店门口 日/外     5 行    对上 1 组
9-3  林夏家 夜/内        3 行    缺分镜

先按提示词表头里的剧本场次对，再按台词对。对不上的行会留在场次下面，可以手动归到某一组。
跨两场的视频组在两场里各算一次。
                                                        [取消]  [导入并对齐]
```

- 三种给法：拖文件、点「选择文件」、直接粘贴文字。`.docx` 用 Agent 附件那边已有的读法（`video/agent-attachments.ts`）。
- 预览是实时的：换文件或改粘贴内容后重新识别。识别期间按钮不可点。
- 一个场次都没识别出来时，不让导入，提示 `没有识别到场次行。场次行的样子是：9-1  日/内  咖啡店`。
- **再导一份**：按场次编号合并。新稿里有的场次整场替换（手动改过归属、文字没变的行保留归属），新稿里没有的场次原样留着。弹窗里会写清楚 `将替换 2 场，新增 1 场，其余 5 场不动`。
- 自己那一条上「导入剧本」旁边有个小菜单：`清空这个项目的剧本`，需要确认，提示里写明对应关系会一起清掉、视频组不受影响。

**人名对应**

- 分镜里常写「女主」「男主」，剧本里写的是名字。工作台从提示词的 `【出场人物】` 里读 `女主（林夏）：…` 这样的行，自动得到 `女主 = 林夏`。
- 自己那一条右侧显示成一个小按钮 `人名对应：女主 = 林夏 等 2 个`。点开是一张小表，可以改、增、删。改了以后重新对一遍。
- 没有人名对应时不核对说话人，只看台词文字，所以不会因为缺一条对应就整句对不上。人名对应写错了（比如把女主对成了别人的名字）才会让这个角色的台词对不上。

### 7. 提示和撤销

- 导入剧本成功：`已导入 3 场 28 行，对上 6 组；1 场缺分镜`（`message.success`）。
- 手动改归属、换成片版本、指定场次、标为没问题：各提示一次，带「撤销」。
- 对齐是自动重算的：视频组的提示词变了（比如用查找替换改过），下次进这个视图时只重算变了的那几组，不提示。
- 不新增快捷键。

## 自动对应的规则

这是云端用用户的一份真实样本试算通过的做法（样本不在仓库里），写成推荐规则。本机可以按用户更多的稿子调整细节，但 `样例/` 里那份编造稿的结果必须和「验收」里的表一致。

### 剧本怎么拆行

| 行的样子 | 认成 |
| --- | --- |
| `9-1  日/内  咖啡店`（场次编号 + 空白 + 其余） | 场次行，开始新的一场 |
| `人物：林夏、周野、店员` | 人物行，记下这一场的人名，不算内容行 |
| `【第1版】`、`【第1版结束】` | 版本块的开始和结束。块外面的行是"两版共用" |
| `△ 门上的风铃响了一声。` | 动作行 |
| `周野（抬头）说："你来了。"`、`林夏（VO）："……"`（名字 + 可选括号 + 可选「说」+ 冒号 + 引号里的话；直引号和弯引号都认） | 台词行，记下说话人和台词 |
| 其他行里带 `「……」` 的 | 小说体：`「」` 里的话当台词（说话人未知），其余文字当描写 |
| 其他行 | 描写行 |
| 空行 | 忽略 |

### 视频组属于哪一场、哪一版

只看提示词第一行的表头：

- `剧本9-1` → 场次 9-1。表头里出现两个场次（`剧本9-1…结尾＋9-2…开头`）→ 这一组跨两场。
- `【第2版】` → 第 2 版；写着「两版共用」或没写版本 → 共用。
- 表头里没有 `剧本` + 场次编号 → 归到「未对上剧本」。
- 场次编号后面的其他符号（括号里的场景名、圈号、「前段」「后段」「精简版」之类）不参与判断。

### 台词怎么对

1. 分镜里的台词取 `【角色】（配音指令：角色｜情绪｜语气：台词）` 最后一个冒号后面的部分（现有的 `video/dialogue-highlight.ts` · `dialogueRanges` 已经在做这件事），并记下它在第几个镜头。角色名里的 `（OS/vo）` 去掉。
2. 比较时两边都去掉标点和空白。
3. 在"同一场、同一版（或共用）"的范围里，按顺序往下对：分镜的每一句台词，从剧本里还没用掉的最靠前那句开始找，最多往后看几句（试算用的是 6 句），对上了就从那里接着往下走，不回头。跨两场的视频组，范围是这两场按剧本顺序连起来。
4. 两边的说话人都能确定时才核对：剧本那句写了说话人，并且分镜的角色经过人名对应后是这份剧本人物行里的名字。两个名字不同就不算对上。小说体的 `「」` 没有说话人，或者分镜的角色换算不出名字，都不核对，只看文字。
5. 分镜这一句只是剧本那句的开头一段时，认作"拆开了"，下一句分镜台词接着对剩下的部分。拼完整就是「原文一致（拆成 N 镜）」。
6. 不完全一样但很像（相似度不低于 0.6）时，认作「台词不一致」。
7. 都对不上的分镜台词不占用剧本行；剧本里没被对上的台词行按下一节的办法当普通行处理。

### 其余的行怎么分

1. 夹在同一组的两句已对上的台词之间的行，归这一组。
2. 落在两组交界处的行（前一句台词属于甲组，后一句属于乙组）：把这一行的文字和两组各个镜头的画面文字比，哪组更像归哪组。
3. 这一场（这一版）第一句台词之前的行归第一组，最后一句台词之后的行归最后一组。
4. 一行只能分给"场次和版本都对得上"的组。这一场没有任何组，就是缺分镜，不往别的场次的组里塞。
5. 和所归的组比下来不够像（低于 0.25）的，标成「靠位置」；够像的标成「画面对得上」。
6. 这一场（这一版）的组一句台词都没有时：只有一组就全归它并标「靠位置」；有多组就按相似度归，都不够像的留在「未分配」。

"像不像"用的是：把剧本这一行切成相邻两个字一组，看其中多大比例出现在那个镜头的画面文字里。

## 数据与旧项目

- 行的身份要稳定：同一场、同一版里文字相同的行，重新导入后还是"同一行"，手动归属才能保留。文字相同的重复行按出现的先后区分。

- 旧项目没有剧本：视图能打开，右栏是导入提示。
- 备份（规则 4）：实施前备份工作台数据目录。新存储在同一个 IndexedDB 库里，现有的备份范围已经包含它，请本机确认。
- 回退：装回旧版后项目正常打开；旧版不读新存储，不受影响。换成片版本改过的「不进连播」会留在视频组上，旧版不认识这个字段，不报错即可。
