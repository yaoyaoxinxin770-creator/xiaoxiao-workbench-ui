## 用户要达到的结果

1. 看片时遇到好看的镜头，按一下 `H` 标出来，分优、良两级，记到具体镜号上。之后能列出所有高光、只看优、连着播、导出一张表。
2. 废片能真正从硬盘上清掉。现在「移入回收站」只是把文件挪进项目目录里的 `.回收站` 文件夹，空间没有释放。
3. 一键把所有采用的版本按顺序导出成一个文件夹，文件名带序号，可以整个拖进 Topaz 或剪映。
4. 在网格里一眼看出哪条是采用的、哪条有高光。

### 一、高光

**怎么标**

- 补漏台里，播到好看的地方按 `H`（或点右侧新增的「高光 H」按钮）：
  - 第一次：标为「良」；
  - 再按：变「优」；
  - 第三次：取消。
- 记在**当前这个版本**的**当前镜头**上（当前时间落在提示词里哪个镜头的时间段）。提示词没写镜头的，记当前时间点；同一秒内再按算同一条。
- 新版本不继承旧版本的高光（和颜色、备注的现有规则一致）。

**标了以后哪里能看到**

- 镜头条上这一格变成金色底，右上角写「优」或「良」。
- 右侧面板多一块「这条的高光」：`镜头 03 · 优`、`镜头 05 · 良`，每条可以写一句备注、可以点 × 取消。点一条跳到那个镜头。
- 时间线上这一格（如果高光在采用版上）右上角一枚金色小标「高光 优」，取最高等级。
- 顶上那一条的数量变成 `待补 5 · 高光 8 · 废片 23`。

**高光清单**（左清单新增页签「高光 N」）

- 列出当前范围里所有高光，按时间线顺序。每行：缩略图、`V4-08 · 1 · 镜头 03`、等级、时间段 `00:03.5–00:06.1`、备注。点一行跳过去。
- 页签顶部两个小按钮：`全部 ｜ 只看优`。
- 「连播高光」：按清单顺序，每条只放它的时间段，连着放完。
- 「导出清单」：存成一张表（`.csv`，用 Excel 能直接打开且中文不乱码），列是：视频编号、版本、镜号、开始、结束、等级、备注、文件位置。弹系统的保存对话框，默认文件名 `高光清单-文件夹名-日期.csv`。
- 空状态：`还没有高光。播到好看的地方按 H`。

### 二、清理废片

**入口**：补漏台顶上那一条新增「清理废片…」；左清单「废片」页签底部的按钮也换成它。网格「筛选与视图」里现有的「一键将废片移入回收站」原样保留。

**弹窗**

```
清理废片                                        ( ) 当前文件夹  ( ) 整个项目
灰底 / 不可用 23 条 · 已在工作台回收站里 8 条 · 合计 4.7 GB

V4-03 · 2    灰底 · 表情不对          182 MB
V4-10 · 2    灰底 · 补洞没用上        96 MB
V4-12 · 1    不可用 · 手部变形        210 MB
还有 28 条，展开查看

! 有 2 条同时标了「采用」「高光」或收藏，已排除，请单独处理。 查看
! 有 3 条在别处存过硬链接分身，分身不删的话空间不会释放。
删除后工作台里保留这条视频的记录，显示「文件已清理」，提示词和参数还能看。官网节点不动。

                       [取消]  [移入工作台回收站]  [删除到 Windows 回收站（31 条，4.7 GB）]
```

- 列出的是：当前范围里的废片（灰底，或标了红色「× 不可用」），加上已经在工作台回收站里、文件还在的记录。
- 每行显示原因和备注的前几个字、文件大小。文件已经不在的不列。
- 「查看」展开被排除的那几条，每条一个「定位」跳过去。
- 大小和"有没有分身"由桌面端读文件得到。读取期间按钮不可点，显示转圈。

**两个动作**

| 按钮 | 做什么 | 能不能找回 |
| --- | --- | --- |
| 移入工作台回收站 | 现有行为：记录进工作台回收站，文件挪进项目目录的 `.回收站` 文件夹。只处理还没进回收站的那部分 | 能，在工作台回收站里点恢复。空间不释放 |
| 删除到 Windows 回收站 | 新增：记录进工作台回收站（已经在的不重复），文件送进 Windows 回收站 | 清空系统回收站之前都能在系统回收站里还原 |

- **不做永久删除。** 文件送不进 Windows 回收站时（比如这个盘关闭了回收站），不删，提示原因，文件原样留着。
- 点「删除到 Windows 回收站」后不再二次确认（弹窗本身就是确认，按钮上已经写了条数和大小）。按钮是危险色。
- 部分失败时，成功的照常完成，提示 `已删除 29 个，2 个没删掉`，并列出没删掉的和原因。
- 完成提示（`message.success`）：`已删除 31 个文件到 Windows 回收站。清空系统回收站之前都能找回`。

**保护**：同时标了采用、有高光、或被收藏的视频，不管是不是废片都不会被这个弹窗处理，单独列出来。

**删掉以后**

- 这条记录留在工作台回收站里，缩略图位置显示「文件已清理」。能看提示词和参数，能「重新编辑」；不能播放。
- 对它点「恢复此视频」：文件还在系统回收站里没还原时，提示 `文件已删除到 Windows 回收站。先在系统回收站里还原，再点恢复`，不做别的。用户在系统回收站里还原后，文件回到原位置，这时再点恢复就和普通恢复一样，「文件已清理」消失。
- 即梦、小云雀官网上的节点和成片不动。
- 同组的其他版本不受影响。

### 三、导出采用清单

**入口**：补漏台顶上那一条新增「导出采用清单」。

1. 点了以后选一个目标文件夹（系统的选文件夹对话框，默认是上次选的）。
2. 在里面新建一个子文件夹 `采用清单-文件夹名-20261114-1530`，把当前时间线上每一格的采用版按顺序放进去，文件名 `001_V4-01.mp4`、`002_V4-02.mp4`…
3. 文件是**硬链接分身**（和现有「保存视频快捷…」同一种），不占额外空间。
4. 没生成的、不进连播的、文件不在本机的跳过。
5. 完成提示：`已导出 14 个到 采用清单-第4集-20261114-1530，跳过 2 组（没生成）　打开文件夹`。提示下面一行小字：`这些是分身，和工作台里的原视频是同一份数据。高清或压缩时请输出到新文件，不要原地覆盖`。

- 目标文件夹和视频不在同一个盘时做不了硬链接。这时问一次：`目标文件夹和视频不在同一个盘，不能做分身。要改成复制文件吗？需要 3.2 GB 空间`，按钮「复制」「取消」。不要退回成 `.lnk` 快捷方式（那是现有「保存视频快捷…」的做法，对送去高清没有用）。
- 编号里有不能当文件名的字符时换成下划线。
- 每次导出都是新的子文件夹，不覆盖、不清理以前导出的。

### 四、网格卡片和详情弹窗

**网格卡片**（规则 8：卡片保持纯画面，只加角标）

- 左下角加一小排标记，和右下角的颜色圆点一样大：
  - 绿色 `✔`：这条是它所在组**手动采用**的版本（自动规则选出来的不显示，否则几乎每组都有）。
  - 金色 `★优` 或 `★良`：这条有高光，取最高等级。
- 悬停显示说明：`采用版`、`高光：镜头 03 优、镜头 05 良`。
- 不新增文字区块，不挪动现有的编号、颜色圆点、「× 不可用」、蓝框和灰底。
- 不新增筛选项。

**视频详情弹窗**（规则 44 的顶部快捷栏）

- 顶部快捷栏在「蒙上灰底」旁边新增三个按钮：`采用`、`高光`、`待补`。
  - 采用：和补漏台里按 `F` 一样。
  - 高光：给播放器当前所在的镜头标高光，良 → 优 → 取消。
  - 待补：记一条镜头类的洞（当前组、当前镜头），弹一个小输入框写备注。
- 弹窗里**不加快捷键**（弹窗已有自己的左右键）。预览图按钮上的字母是补漏台里的快捷键，弹窗里不显示。
- 右侧信息区加一块「这条的高光」，内容和补漏台右侧面板的那一块相同。

## 数据与旧项目

| 新增 | 放在哪 | 内容 |
| --- | --- | --- |
| 高光 | 每条视频记录的摆放信息上一个可选列表 | 每条：镜号（没有镜头时为空）、开始秒、结束秒、等级（优 / 良）、备注 |
| 文件已清理 | 每条视频记录的摆放信息上一个可选时间 | 文件被送进 Windows 回收站的时间。文件还原后清掉 |

- 旧项目没有这些字段等于"没标"。
- 清理废片**不删除生成记录**，只处理本机文件和项目目录里的文件索引。提示词、参数、任务编号、参考素材的记录都留着。
- 被清理的视频如果是某个洞的垫图来源：垫图已经入库的不受影响；还没入库的，垫图位置显示「原视频文件已清理，换一帧」。
- 采用版指向的记录不会被清理（有保护）。
- 导出采用清单不改任何工作台数据，只记住上次选的文件夹（沿用现有「保存视频快捷…」记文件夹的地方）。
- 备份（规则 4）：实施前备份工作台数据目录。**清理废片的验收必须在测试项目或用户明确指定的废片上做**，不要拿用户的正式项目批量试删。
- 回退：装回旧版后，带高光和「文件已清理」字段的项目能正常打开；旧版把文件已清理的记录当成"本地文件不存在"处理。请本机确认不报错。
