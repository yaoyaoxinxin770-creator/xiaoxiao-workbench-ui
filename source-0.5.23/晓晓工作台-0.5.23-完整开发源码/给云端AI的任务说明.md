# 给云端 AI 的任务说明

仓库中的“晓晓工作台-0.5.23-完整开发源码.zip”是当前本机个人版的完整开发源码包。请用云端终端将它解压到独立目录，保留目录结构，先读《先读我-0.5.23.md》、AGENTS.md、《工作台功能保留规则.md》和“云端交接”目录。

我希望你基于现有工作台进行设计和开发，完成后把代码交回本机 AI，由它负责差异合并、本机验证、打包和安装。

1. 如果你已经根据旧的 0.5.22 前端包做了界面，请保留你的改动，以本次 0.5.23 为较新业务基线比较合并，不能丢弃新修复，也不能直接覆盖已完成的设计。
2. 沿用现有 Next.js/React/TypeScript 前端、Electron 桌面与现有后台接口。源码可读可改的范围比旧 UI 包更完整，但实施范围仍以我在会话中给出的具体任务为准。不要仅因增加了源码而自行实现所有曾讨论的功能。
3. 继续完成我已指定的 UI 设计和实际编码；涉及后台时结合完整调用链定位。对新的后台升级建议先说明收益、影响和验证办法，待我指定后实施。正常范围内的代码编辑不需要逐文件反复询问。
4. CLI 仍在本机运行。你可以开发调用逻辑并通过模拟执行器测试，不能为了适应云端而改掉 Windows 路径、托盘、加密、账号隔离或固定 VBS 启动方式，也不能用模拟结果声称真实官网已生成成功。
5. 保护近期修复：Agent 切组/手工编辑后的迟到回复保护、账号独立操作记录、原视频历史素材保留、用户明确移除优先、画布引用完整性校验、原任务身份和扣费确认。
6. 保留未涉及的功能、入口、默认值、快捷操作和已有数据；行为改变应明确说明。UI 可用虚构数据建立独立 design-preview，不能用假数据覆盖生产接口/store。
7. 完成后返回：改好的完整源码或工作分支/PR、CHANGES.md、INTEGRATION.md、VALIDATION.md、预览截图及预览入口。依赖改动同步锁文件；说明与 0.5.23 基线的差异。不要只交截图或编译后的压缩脚本。
8. 验证结果写明实际执行、通过、失败、未执行及原因。当前个人版全量入口覆盖166项 test-*.mjs；分享版两项排除且不计通过。云端缺少Windows/官方运行时时，不篡改断言、不静默跳过或假报全量通过，将待完成部分交回本机。
9. 不接入我的真实账号，不提交真实付费生成，不访问或上传个人数据，不代替本机安装。本机安装时会保留上一稳定版和按需的数据备份。
