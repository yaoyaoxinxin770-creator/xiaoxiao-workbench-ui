# 即梦 CDP 直连使用说明

这次接入的是本地浏览器自动化桥，不调用即梦私有生成接口。默认使用本机 9333 端口，也可以在设置中修改。原来的扩展方式仍可手动选择；任务执行中或待核对时禁止切换，不自动跨通道重发。

## 开始使用

1. 保存当前工作并关闭旧工作台，再双击根目录的「启动即梦工作台.vbs」。这次改动加载于源码启动入口，未重新制作便携 EXE。
2. 在项目首页或工作区点击「即梦直连设置」。
3. 连接方式选「CDP 直连」，端口默认 9333，点击「保存方式与端口」。
4. 点击「启动专用浏览器」。首次在这个浏览器登录即梦，打开一个画布项目，再打开右侧 Agent 对话。
5. 点击「刷新画布列表」，选择目标，点击「连接此画布」。多个画布不会擅自选一个。
6. 回到项目，先用一组分镜核对素材、@ 位置和实际任务受理，再运行整批。

如果已有自动化 Chrome 在其他端口运行，填入对应端口并保存，然后刷新列表即可。所谓“Gemini Chrome”不是必须的浏览器品牌；关键是该 Chrome 实例确实启用了调试端口。启动按钮会复用已存在的端口，不强制关掉用户的浏览器。

专用资料目录位于 Electron userData 下的 cdp-bridge/chrome-profile，登录态与日常 Chrome 分开。程序只把调试端口绑定到 127.0.0.1。自定义 Chrome 可在启动工作台前设置 JIMENG_CHROME_PATH 为 chrome.exe 完整路径。

## 新桥接做了什么

- 主进程通过 Playwright 的 connectOverCDP 连接浏览器，直接检测指定标签；不依赖网页心跳领取任务或 MV3 service worker 传递命令。
- 在命名隔离世界加载项目现有 content.js，复用真实上传、素材就绪等待、内联 @、完整提示词校验。
- 文件在宿主进行目录边界及真实路径检查后，按 2 MiB 分块送到页面执行器；不从 Cookie 或私有 API 取素材。
- 同一条任务只允许一次正式发送。发送意图先写磁盘，再发鼠标事件；通信错误不会让点击重新获得资格。
- 不点击运行中的停止方块，不覆盖编辑器中已有的文字或附件。
- 记录发送前任务卡和对话轮次基线。优先核对同一会话中新增的最新轮次、该轮完整最终提示词，以及该轮下的视频任务块；旧的最新轮次必须已顺移，避免历史内容滚入 DOM 被误认。也兼容“新增视频任务卡内含本次完整最终提示词”的页面结构。余额下降、0 积分、旧“生成中”、单独清空输入框都不能让 CDP 路径判成功。
- 断线重新附着原标签，查询原执行记录；不重传整条任务，不刷新原画布。页面刷新导致记录丢失时保留磁盘锁，要求人工核对。
- 停止会阻止后续宿主输入操作，并让页面等待循环退出。它不撤销即梦已经接受的生成。
- 原解析层和资产匹配规则继续沿用；本次没有重写 P01/G01 语法，也不能据此声称所有第三方 MD 格式都已兼容。

## 异常恢复

「核对原任务（不重发）」只读取同一标签的原记录和新增任务证据。证据稍后出现时可以确认成功，不重新发送。当前执行请求还在等待时，回执会自然返回原队列。

任务请求已经返回失败、或工作台曾重启时，核对结果不会自动把旧队列分镜标成完成，也不会自动续跑后面的批次；请按即梦实际结果处理队列，避免再次执行已成功的分镜。

「人工核对后结束本条」会明确确认你已在即梦检查本条状态；它保存人工核对记录并解除阻塞，不会重发或声称生成成功。页面执行器尚未停止时不能释放。原浏览器暂时失联且无法核实原标签是否存在时，也不会解除锁。

待核对记录为 userData/cdp-bridge/cdp-pending.json，最近结果为 cdp-last-result.json，设置为 cdp-config.json。记录包括目标标签、提示词哈希、阶段和点击意图；不要通过手动删除待核对记录来重试。

## 仍需真实站点验收的边界

CDP 改变的是连接与控制通道，不能保证网站 DOM 永不变化、网络不中断或浏览器进程不退出。已只读检查当前打开的即梦画布，确认用户正文位于 prompt-value-container，视频任务位于同一轮的 video-nodes-container，已接入这些公开 DOM 结构；不需要把积分余额当成功证据。若后续网站改版，只在任务详情展示提示词、只展示改写/截断文本，或历史虚拟列表无法证明轮次前移，当前保守匹配将停在待核对，不会猜测成功。

不要同时在同一个目标画布运行另一套自动化或手动提交同样提示词。公开 DOM 证据无法区分两个同时提交且文本完全一致的任务。新卡“生成失败”仍可证明曾受理，不能把受理确认理解为视频最终生成成功。

旧扩展路径仍保留其原策略，包括发送重试与余额确认；以上单次发送和证据规则仅适用于 CDP 直连路径。

## 验证

在根目录运行：

    node desktop-app/run-tests.cjs

全量源测试覆盖 desktop-app 和 jimeng-canvas-extension 的所有 test-*.mjs。output 与 recovery_backups 是历史结果，不属于当前源测试套件。

新增测试使用临时资料目录中的真实 Chrome 和独立 Electron 实例，验证隔离执行器、可信点击、一次发送、无关任务拒绝、真实同轮对话结构、零积分无任务拒绝、迟到证据恢复、断线重连、重启锁定、素材分块、取消、并发防护及真实工作台 IPC/设置入口。不使用用户即梦账号、不上传用户素材、不产生生成费用。
