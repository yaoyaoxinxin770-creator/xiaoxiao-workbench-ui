# 字字动画场景 · 复用说明

本轮只改工作台的**字字动画场景**（场景导航 03）。即梦自动发送场景（`jimeng-canvas-extension/`
里的 `calibration.js` / `content.js` / `service-worker.js` / `sidepanel.js`）一行没动。
`F:\RuanJian\字字动画\字字反推记录\` 里的还原产物只读，没有写入。

---

## 1. 这轮解决的是什么问题

改造前，工作台的字字动画场景能选插件、能提交任务，但有两个洞会在真用起来的时候才炸：

| 洞 | 后果 |
|---|---|
| 插件 `context` 的字段名和键类型不符合字字动画插件协议 | 现成插件一个都跑不起来，而且不是报错，是静默拿到空值 |
| `@素材名` 只有 `@image1` 一种展开格式，也没有素材数量上限 | 换个模型就得改代码；素材超量时「payload 里有第 4 张图，但前缀只声明到图 3」 |

这轮把两件事按还原出来的原设计补齐了。

## 4. 两个核心改动

### 4.1 模型族 —— 编号只有一套

原程序把三件事收归成「每个模型归属一个族」：`@实体名` 展开成什么 token、要不要出
「图1是张三」这种参考前缀声明、最多带几张素材。工作台现在照着做了：

- 图片族与视频族互不混用（图片模型不吃视频/音频参考，所以图片族只有 `images` 一个上限）。
- 出厂族：视频侧 `none` / `jimeng_2_0` / `jimeng_2_5` / `h3` / `wan_3_0` / `zzdh_video`；
  图片侧 `none` / `omni_nano` / `omni_image2` / `zzdh_image`。
- 三层解析：出厂默认 → 同 id 覆盖 → 新 id 自建族。覆盖层存在工作区状态的
  `familyOverrides` 里，删掉某个 id 就等于「恢复默认」。
- 归属解析优先级：**通道里显式选过的族 → 按模型名推断 → 默认族**。推断结果只在读取时
  兜底计算，绝不写盘 —— 所以换模型不会把你手动选过的族冲掉。
- 图片 / 视频 / 音频三类槽位**独立 1 基编号**，去重按归一化后的路径（相对/绝对、大小写
  不同的同一个文件只占一个槽位）。
- 超限素材**既不展开成 token，也不写进参考前缀，也不进 payload**，并在界面上标红
  「超出族上限，这张不会发给模型」。

> ⚠️ **诚实标注**：族的 id、字段、校验规则、预览规则来自还原产物；但各族 `limits` 的
> 具体数字在原程序里是 `.pyd` 内的 `_BUILTIN_FAMILIES`，取不到。现在的数字（如即梦 2.0
> 的 10 图 / 1 视频 / 1 音频）是**工作台的出厂默认值**，按你实际用的模型改即可 —— 反推
> 报告里也提到 Seedance 在原程序三处的上限本来就互相打架（10图1视频 / 9/3/3 / 30/10/10）。

### 4.2 插件宿主 —— 现成插件直接能跑

已验证：把 `plugins/image_plugins/example`（字字动画真源码插件，一字未改）拷进来，
工作台能直接跑出 `0003_07_1_0.png`、`0003_07_1_1.png` —— 批量数量、viewer 索引、生成轮次、
输出位置、命名规范全部对得上。

宿主必须做对、且做错了只会静默失败的三件事：

1. **`sys.path`**：插件写的是 `from plugin_utils import load_plugin_config`，但它自己只
   `append` 了插件目录和类型目录，而 `plugin_utils.py` 在 `plugins/` 根目录。宿主把
   「插件目录 / 类型目录 / plugins 根目录」都放进 `sys.path`，并把本宿主目录垫在最后兜底。
2. **CWD**：`plugin_utils` 用相对路径 `user_resources/plugins/{类型}/{插件名}/config.json`
   定位配置，即相对进程 CWD。宿主固定把 CWD 设成
   `%APPDATA%/<工作台>/typetale-host/`，所以配置是**全局的**，不跟项目走 ——
   否则同一个插件在每个项目里都要重填一次 API Key。从字字动画拷过来的 `config.json`
   放进同样的相对路径就能直接生效。
3. **`reference_images` 的键类型**：协议是 0 基**整数**键字典，但 JSON 对象键只能是字符串。
   插件普遍用 `all(isinstance(k, int) for k in keys)` 判断要不要包成 `{"参考图片MAP": ...}`，
   字符串键会让这个判断为假，接着 `reference_images.get("首帧")` 永远取不到值。
   宿主在 `json.loads` 之后把数字字符串键转回 `int`。

另外：

- `progress_callback` 过不了 JSON，由宿主注入，插件调用后以 `__TYPETALE_PROGRESS__=` 行回传。
- 插件 `raise Exception("PLUGIN_ERROR:::原因")` 表示「别再重试」，宿主剥掉前缀并打上 `fatal`。
- 插件返回了路径但文件不在盘上（吞掉自己异常的典型表现），宿主报 `missingFiles`，**不算成功**。
- 插件列表里，`# Auto-generated bridge` 开头的桥接桩和只有 `.pyd` 的插件会被标注并禁用，
  不会等到执行阶段才炸。

## 5. 需要重写后端的地方（都还没有实现，别当成有）

以下能力原程序在 Cython `.pyd` 里，反编译不出来。工作台现在**没有**这些实现，要么按
`.pyi` 签名自己写，要么接现成的 ComfyUI / SD-WebUI API。

| 能力 | 原接口（仅签名，实现在 .pyd） | 现状与建议 |
|---|---|---|
| 生成引擎调度 | `services/image_generation_service.pyi`、`backend/generation_bridge.pyi` | **需要重写后端生成调度接口**。工作台目前只有「通用视频 API / 插件 / CLI」三条直连路径，没有队列编排、失败重试、并发槽位 |
| 模型目录 | `backend/generation_catalog_service.pyi` 的 `register_catalog_item(... model_family=..., constraints=...)` | **需要重写后端模型目录接口**。现在模型名是手填的，没有可选模型列表，也没有 `constraints.maxInput*` |
| 族存储 CRUD + 族编辑器 | `backend/model_family_service.pyi`（存 `user_resources/model_families/{image\|video}/{id}.json`） | 部分替代：族的**运行时逻辑**（解析、渲染、上限）已经有了，覆盖层数据结构和校验/预览函数也在（`typetaleValidateModelFamily`），但**界面上还没有族编辑器** —— 想改上限或自建族，目前只能改工作区状态里的 `familyOverrides`。也**还没有**按原路径落盘的 CRUD 与「恢复默认」按钮 |
| 参考槽位收集 | `utils/reference_slots.pyi` 的 `collect_from_items` / `collect_from_maps` / `collect_frame_slots` | 已按 docstring 重写等价逻辑在 `compilePrompt` 里。但原实现会**丢掉磁盘上已失效的文件**（留着会让编号比实际上传的素材多算而错位），工作台这一步**还没做**——素材路径失效时编号可能错位 |
| WebSocket 消息总线 | `backend/ws_server.pyi` | **需要重写后端 WS 接口**。原前端靠 WS 推送生成进度；工作台现在是一次性 `execFile`，只有结束时才有结果 |
| 插件市场 / 安装卸载 | `tool_plugin_install` / `tool_plugin_uninstall`（前端 JS 里可见调用，后端在 .pyd） | **需要重写后端插件市场接口**。工作台只能扫本地目录，不能安装/卸载/更新 |
| 插件自带 UI | 插件的 `ui/index.html` + `plugin-sdk.js` | **需要实现 iframe 插件 UI 宿主**。工作台现在按 `get_params()` 的返回值现画一张朴素表单；带自定义 UI 的插件（`model_family_ui: "self"`）只会显示这张表单，不会加载它自己的界面 |
| LLM / VLM 调度 | `llm_platform` / `llm_model` / `vlm_model` 等配置键（前端可见，后端在 .pyd） | **需要重写后端 LLM 接口**。`zzdh_drama_agent` 框架（96 个真源码文件）还没接进来 |

## 6. 怎么用

1. 场景导航点「03 字字动画工作区」，先从项目管理打开一个字字动画项目。
2. 左侧竖条「模」→ 选模型类型（视频/图片）→ 填模型名 → **模型族**下拉会按模型名推断一个
   默认值，说明行会写明 chip 格式和素材上限；手动选过就固定下来。
3. 「件」→ 填插件根目录（比如你从字字动画拷出来的 `plugins/`）→ 扫描 →
   点一个插件，下面会显示它的 `get_info()` 说明和 `get_params()` 参数表，填完保存即写进
   该插件的 `config.json`。
4. 粘贴整稿 → 解析分镜 → 在提示词里用 `@角色名` / `@场景名` 引用素材，右侧「参考项」会显示
   每个槽位的编号和 token，超限的会标红。
5. 需要首尾帧生视频的，在提示词下面选首帧/尾帧 —— 它们是**生成模式的输入位**，不占参考
   槽位，也不受族上限约束。
6. 「生成视频」提交当前分镜，或「批量执行所选」。

Python 解释器默认取 `python`，可用环境变量 `TYPETALE_PYTHON` 指定。
