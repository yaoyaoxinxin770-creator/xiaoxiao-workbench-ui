# 小云雀画布直生成

1. 启动晓晓的 AI 工作台 0.4.31。
2. 在已登录小云雀的 Chrome 个人资料中打开扩展管理页。首次连接时开启「开发者模式」，点「加载已解压的扩展程序」，选择 `F:\下载\skill\晓晓的AI工作台\jimeng-canvas-extension`；扩展名称是「即梦画布批量投放工作台」，版本应为 0.20.7，当前也包含小云雀连接器。如果已经安装，点该扩展卡片的重新加载按钮，确认启用。
3. 只保留一个该项目的官网画布标签页。视频创作台项目侧栏点「小云雀画布」，保存该项目画布链接，点「检查浏览器连接」，显示已连接后开始创作。

这是 CLI 准备节点与浏览器扩展操作官网生成面板的组合方案，需要桌面程序和 Chrome 画布保持打开。每次生成会在本项目的画布中新建独立视频节点，支持 Seedance 2.5 和 Seedance 2.5 Draft 的全参考模式。首尾帧和样片转成片先在官网原节点处理。连接器复用已有扩展权限，不需要提供 Cookies 或授权密钥。

网页未登录、目标页面未打开、连接器未就绪、同一画布存在多个标签或参数不一致会停止发送，避免转用左侧项目列表。中断后的已点击任务会回查原节点，不通过重复发送猜测是否成功。
