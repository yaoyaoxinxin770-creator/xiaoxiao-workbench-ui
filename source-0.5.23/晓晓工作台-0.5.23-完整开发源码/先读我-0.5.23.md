# 晓晓工作台 0.5.23 完整开发源码交接

本包供用户上传到私有 GitHub 仓库，让云端 AI 继续设计和开发，再交回本机 AI 整合、验证、打包安装。它是开发源码包，不是可双击运行的安装包；不改变工作台继续在 Windows 本机运行的定位。

## 基线与读取顺序

1. 阅读根目录 AGENTS.md、工作台功能保留规则.md、CLAUDE.md。
2. 阅读 云端交接/最新修复与保护边界.md、云端交接/源码导览.md、云端交接/云端开发与验证.md。
3. 按用户在本轮会话指定的具体任务开发。源码完整不代表授权全面重写或一次实现所有升级建议。

源码 desktop-app/package.json 与本机磁盘已安装 app.asar 的版本均核对为 0.5.23；本次没有启动、关闭或升级正式程序。桌面版本不要与前端自身 package.json 的 0.1.0 或上游 VERSION 混淆。

此前单独的 UI 交接包基于 0.5.22。本包提供较新的完整源码基线；如果云端已经做了 UI 改动，请保留这些改动，比较差异后接入 0.5.23，不要整目录覆盖任何一边。详细文件 SHA-256 见 SOURCE_MANIFEST.json。

## 包含与排除

- 包含：Next.js/React/TypeScript 前端、Electron 桌面源码、CLI 调用/适配源码、旧执行器兼容层、Go 后端源码、模拟测试与合成媒体夹具、依赖锁文件、构建脚本、许可证、CLI 版本来源资料、最新功能规则及交接说明。
- 不含：本机工作台数据、真实项目与原始素材、账号密钥、登录会话、浏览器资料目录、.env 实际配置、安装包、EXE/MSI/DLL、node_modules、.next、Git 历史、历史备份、旧输出日志。
- 保留 .env.example，其中是上游示例默认值，不是本机正式配置。不要把示例默认口令直接当生产配置。
- 保留前端的 3D 导演台静态网页资源、模型和素材；测试目录的 hover-synthetic.mp4 是合成测试夹具，不是用户视频。
- 第三方 CLI 程序与小云雀预编译运行库不随包传输；保留版本/许可/适配脚本。运行时依赖详见 云端交接/云端开发与验证.md。
- 共用目录中保留分享版源码及测试文件作为现有源码的一部分；它们不是本轮维护、执行、打包或验收对象，不会生成分享版程序。

## 怎么上传

在用户已经创建的私有仓库里，添加文件 → 上传文件，将本 ZIP 本身上传并提交即可，不必一次拖入数百个文件。让云端 AI 在终端解压到独立目录，再读取说明。不要把本机正在使用的整个文件夹拖到 GitHub。

解压后先建立 0.5.23 源码基线提交，再按任务建立工作分支；最终需要将改好的展开源码提交，或返回改动源码 ZIP，不能只修改 ZIP 文件而没有可审阅的代码差异。
