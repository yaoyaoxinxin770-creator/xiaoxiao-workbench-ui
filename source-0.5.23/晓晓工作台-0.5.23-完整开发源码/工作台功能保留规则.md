# 工作台功能保留规则

本文件由根目录 `AGENTS.md` 引用，是用户审阅确认的功能行为清单。编号对应审阅稿，便于后续指定修改。

用户最新明确要求优先。用户调整某项功能时，同步修改相应条款，替换旧描述；未涉及的条款继续保留。需求确认、实现完成、技术验证、用户体验验收是不同状态，不能相互替代。本清单不要求每次更新都测试全部功能，也不授权顺带实施所有待办。

## 一、维护和更新规则

1. **保留已有功能。** 本次需求没有涉及的功能、入口、默认行为和快捷操作，不得在优化、重构或换界面时顺带删除或改变。确实需要调整的，先说明具体影响并取得用户确认。

2. **以最新要求为准。** 同一功能出现多次要求时，采用最后明确拍板的行为；不得因为旧文档、旧代码或设计稿，把已经取消的功能重新加回来。用户要求改变功能时同步更新规则，无需另外提醒；未要求改变的规则不得擅改。

3. **只维护个人版。** 未经重新明确要求，不修改、测试、打包或更新分享版。

4. **保留恢复能力。** 按用户2026-11-02最新要求，当前保留0.5.19和0.5.20完整程序；含第1版在内的更早程序版本已获用户授权按本轮清单清理，不再永久保留第1版。此次同时获准清理旧分享产物及U类旧工具资料，Nana H3项目和其原始压缩包继续保留。后续更新继续保留上一稳定版；涉及数据结构变化时，先备份相关数据。程序备份与项目数据备份分别说明，旧程序可清理不等于历史项目数据备份可一并删除。

5. **尽量使用 F 盘。** 缓存、构建和测试临时文件优先放在 `F:\RuanJian\codex` 或约定的 F 盘目录，避免持续占用 C 盘。

6. **接手先核对现状。** 新会话或另一个 AI 接手时，先核对当前版本、最新修改和未完成事项；不得拿旧代码覆盖其他 AI 已完成的修复。

## 二、外观和布局

7. **沿用柔粉方案 A，四套皮肤并存。** 默认皮肤仍为暖樱粉（柔粉方案 A 的精修版），保留该风格的项目管理页、按角色和场景归档的资产库。按用户2026-11-04确认，皮肤菜单依次为“暖樱粉 / 云母白 / 影视暗房 / 漫画分镜”：云母白改用雾白工作室配色（中性灰 + 靛蓝），影视暗房改用胭脂墨黑配色（胭脂粉 #FF7CA2 × 墨黑 #000000，主按钮粉底黑字），漫画分镜为新增皮肤（米白纸张、墨线硬投影、番茄红）。原有三个菜单名称与存储值不变，切换皮肤只改外观。后续用户明确批准的局部优化继续保留，不按早期设计稿回退。

8. **视频卡片保持纯画面。** 使用直角长方形，不在视频下方重新添加标题、渠道、时间等独立说明区块。选择圈仍直接覆盖原编号，编号不让位；Agent 侧栏打开期间，当前对象视频以描边和编号旁的“Agent”角标标出，收起侧栏即消失。

9. **视频与资产分开。** 项目侧栏采用“视频 / 资产”切换，项目简介入口保持移除状态。

10. **保留侧栏收起与伸缩。** 最左侧功能栏可通过顶部按钮收起；项目目录栏可调整宽度、收起为图标状态，向左拖到收起位置也能收起。目录缩进和顶部工具栏保持紧凑，避免大片空白。

11. **保留提示词区域的浮动布局。** 提示词滚动到底不保留定位镜头产生的整屏空白；提示词面板外的左右空白保持透明，不重新铺满白色背景；保留已有缩放、收起和展开能力。视频列表按浮动提示词框实际高度增加底部滚动余量，使最后一排能滚到面板上方；不在提示词输入框内部增加空白。

12. **不恢复已经取消的入口。** 资产页顶部原“隐藏提示词”按钮已要求移除，后续更新不得自行恢复；此处仅针对该旧按钮，不取消提示词面板已有的收起、展开功能。提示词参考条中的“一键定位 / 按文件夹恢复”卡片保持移除；素材库中的批量恢复入口，以及单个素材的“绑定 / 定位”保留。

13. **精简素材详情。** 保留名称、别名、分类、禁用、优先级、角色 / 分组等需要的设置；别名支持多个，用于搜索和自动匹配，仍遵守类型、禁用、歧义和当前版本规则，不改原名称或文件；不重新加入已经划掉的匹配名称输入框、描述、作者、状态字段。移除界面字段不等于删除历史数据或自动匹配能力。

14. **详情滚动按钮位置固定。** 提示词置顶箭头放在“复制”右侧；置底箭头放在底部操作区右侧，不再占用顶部独立一行。

## 三、视频组、目录和导入

15. **文件夹独立归属。** 视频组从父文件夹移到子文件夹后，父文件夹默认不继续显示它；“全部视频”汇总当前项目。不能把普通文件夹默认变成包含所有子目录的视频集合。视频支持颜色标记，右键颜色名称前显示对应颜色圆球；右键菜单将“下载视频”替换为“保存视频快捷…”，放在“标记颜色”下方，复用已有快捷方式能力，其他下载入口保留。每种颜色可自定义用途；“显示颜色”勾选只控制视频上的颜色圆点，不隐藏视频，独立的“按颜色筛选视频”才筛选当前目录的视频。标色与备注按每条具体视频独立保存，不连带同组其他版本；点击颜色圆点编辑该视频备注，鼠标移到颜色圆点上立即显示备注信息（无延迟）；若视频带有备注，视频详情在“作品信息与生成详情”上方展示该备注。历史组颜色仅兼容显示，新标色不再写到整个组。视频页“筛选”面板提供生成渠道（即梦、Oii、小云雀）、补帧状态（全部、已补帧、未补帧）、模型（仅限当前项目使用过的模型）、排序、隐藏失败及清除筛选，不展示生成状态、审片状态、日期范围和活动筛选。视频组右键不显示“隐藏视频组”，改为“删除视频组”，删除前说明范围并确认，已有本地文件和官网节点不删除；在“删除视频组”正上方提供“打开视频文件夹位置”，点击直接在系统资源管理器中打开该视频组所在的项目本地目录并定位文件。视频卡片右上角悬浮操作按钮顺序固定为：第1个“重新编辑”（画笔图标）、第2个“发给 Agent”（机器人图标）、第3个“收藏”（星标图标）。

16. **选择视频不自动弹框。** 勾选视频只更新选择状态；批量操作面板由顶部对号按钮主动打开。

17. **搜索替换沿用最终布局。** 左侧输入查找内容，输入框右侧放大镜执行搜索；中间执行替换，右侧输入替换内容。不恢复旧的独立“替换视频提示词”按钮和“保存此文件夹全部视频快捷方式”按钮。

18. **替换范围跟随当前目录。** 选“全部视频”作用于当前项目全部视频组；选具体文件夹只作用于该文件夹，不串到其他项目或目录。仅替换尚未生成成片的节点提示词；已生成视频保留原提示词、参考素材和参数，正在生成、补帧或结果待核对的任务也不改写。

19. **整稿导入只取视频提示词正文。** 导入或拖入整份 MD 时，只提取第三部分的视频提示词，排除前面规划、外层说明和末尾确认事项；文本预览区也展示提取后的内容。已有直接粘贴纯视频提示词的导入方式继续保留。

20. **保留原视频编号。** 支持已有数字编号、连字符编号和 `V01` 等字母前缀编号；承接编号不另拆成一组，排序、移动和筛选不擅自改编号。载入本组时记住来源项目、目录和组，提交及异步完成沿用该来源，不跟随当前浏览目录；只有无来源的新建内容使用当前目录。载入本组、建立节点、等待生成/补帧和成品回传均沿用原视频组的位置；占位卡变成任务卡或成品不能移到末尾，用户明确手动调整的顺序继续保留。即梦画布节点按本组视频编号命名（含V前缀），补帧成品保留对应编号，不统一叫“视频草稿”。

21. **重新编辑必须对应正确版本。** 新版本使用的新提示词、参考图片和音频，必须同步用于渠道提交、工作台详情和再次编辑；旧版本仍保留自己的历史参数。 载入另一组参数时先清空当前提示词、图片、音频、视频及首尾帧，再仅载入该组参数；过期的异步载入不得回写。重新编辑已生成视频时，必须100%保留该视频生成时实际使用的参考图片与音频素材；即使资产库中相关素材已被同名替换、被设为禁用、或被其他同名优先1素材覆盖，重新编辑与载入该视频时绝不篡改、替换或丢失原视频的真实参考材料。历史素材保留标记必须贯穿提交清单、画布规划与回读核对，不能只在编辑器显示正确；不改变资产库原禁用状态。原素材确实不可读取或画布少接收一项时应报错阻止，不得静默减少参考继续生成。重新匹配只保留当前提示词对应的参考素材，不累加上一组遗留材料。提示词顶部提供上一组、当前组下拉列表和下一组；资产页保持不动，按当前组所在文件夹切换，只载入参数、不自动生成。同次审阅中切走前保留未提交编辑，切回恢复；普通载入本组仍可恢复该组原参数。

22. **新成片与播放能力保留。** 模式一、三中未点开查看的新成片保留小圆点提示；已有视频的播放、详情和重新编辑不能因界面更新失效。

## 四、素材和自动匹配

23. **空格差异不阻碍同名匹配。** 例如“女主 居家睡衣”和“女主居家睡衣”应匹配；明确服装、状态和版本优先，不能因此误用同角色另一套图。

24. **图片和音频分别匹配。** 同名人物图不能代替声音；小云雀、即梦和Oii统一使用以下音频匹配预算：Seedance 2.0本组全部参考音频总时长不超过15秒，Seedance 2.5（含Draft）不超过30秒，不再以3条为工作台匹配上限；未知时长须先核实。其他模型及渠道明确不支持音频等真实限制保留，也不能因重复记录重复计算同一音频时长。

25. **同一个文件不制造假歧义。** 多条历史记录指向同一文件时，应识别为同源素材；画布中多个节点经内容核对属于当前文件时，稳定复用其中一个，不再要求手选。不同文件仅仅同名，仍需区分。展示去重和复用不能擅自删除历史数据、覆盖画布旧素材或破坏其他项目引用。

26. **本次选中的素材优先并自动绑定。** 以本组当前已选参考文件及对应的 @ 引用为准，先采用其明确身份，再处理画布同名候选。已有经过核实的同文件节点就复用；内容不同或无法核实相同时，上传当前文件并绑定，不能因画布存在同名旧节点拦住生成。项目素材可以确定且需要加入时，继续自动补齐。项目库可确定、本地文件可读取而画布未绑定时，普通“开始创作”应自行补传并绑定，不把手动画布设置作为必选步骤；补齐的引用同步进入本次详情与再次编辑的参数。准备失败也保留原视频组占位。只有本组自身选择了多个无法区分的不同版本等情况才要求选择；已明确配置的同级多图引用保留。

27. **尊重用户的引用选择。** 本次明确选中的素材优先于旧的画布名称绑定；不能仅凭旧绑定有效就用旧文件覆盖当前文件。禁用状态用于普通自动匹配；重新编辑或Agent修改原视频时按第21条保留该视频实际使用的历史素材。用户本次明确移除仍优先，不能自动恢复或换成另一张优先素材。关闭自动匹配后，不在载入、粘贴或提交时偷偷补素材；“重新匹配”只执行一次，不改变开关。 自动匹配开关位于视频页顶部工具栏，不占用提示词参数栏；保留独立重新匹配入口，提示词区垃圾桶始终可见。

28. **同名替换文件后继续可用。** 本地图片被同名新文件替换后，预览、拖拽、`@` 引用和提交应使用新内容；不能出现能看到、能 `@`，却不能拖入的情况。图片、音频和视频的画布复用以文件内容身份核对，按账号、画布、类型隔离；同文件后续继续复用，内容变更作为新素材，旧任务仍保留原引用。

29. **保留素材快捷操作。** 素材库支持右键打开所属本地文件夹、设为优先、禁用 / 取消禁用；角色目录和人物分组保留右键置顶人物 / 取消置顶，角色独立展示库内的单图及其详情变体不再提供角色置顶菜单，置顶后左侧剧目角色与右侧人物卡片同步移到最靠前位置，左侧头像圆圈外显示明显彩色描边；左侧角色条目可右键“不在角色目录显示”，并提供恢复显示入口，只隐藏该目录条目，不删除、不禁用、不移走资产；提示词上方的参考小图也支持右键打开所属本地文件夹。 右键支持替换图片和删除素材。替换仅更新图片文件及其位置，保留原资产身份、名称、分类、角色分组、优先和禁用等设置；A被B替换后，打开本地文件夹指向B。替换前的旧图片仍保留在当前项目该角色的禁用库，资产库替换支持Ctrl+Z撤销、Ctrl+Y重做，同次运行按项目隔离；撤销恢复图片位置和原内容，不删除原文件，不影响提示词区域自己的撤销。详情同组小图可右键移到未分类或删除该素材，原文件保留。原图文件不删除；资产页禁用库图片正常清晰显示，不降低透明度，@引用库的禁用项以灰淡样式区分；优先图片始终排在普通图片前，并按设为优先的先后依次排列，不受名称、创建时间等排序影响；取消优先后紧随仍处于优先的图片，不退回原来的远处，顺序重启后保留；最近禁用的图片在禁用区靠前，右键文案为“取消禁用”。支持从资源管理器拖一张图片到资产卡片替换，拖入时显示替换区域；提示词参考小图支持从资产库拖入另一张图，只替换目标位置并可撤销。提示词正文引用图片点击只放大预览，音频点击试听，不打开替换选择列表；手动将参考A替换成B后，自动匹配与提交不得丢弃B，详情与再次编辑保留B。拖拽完成或取消后清除浮层虚线；待补图片卡与已有图片卡均显示替换提示，只接受同类型素材，图片不能落入已有或待补音频/视频卡。@引用库的Elements默认按名称分组，收藏默认不分组，各自独立，不受资产页分组设置影响；未禁用素材始终排在禁用素材前。菜单将置顶、优先和禁用放在前面，打开本地所在文件夹放在最后。删除沿用当前项目移除方式，保留原文件。

30. **归档不等于全部引用。** 按角色、场景归档只影响组织展示，不能因为属于同一角色，就自动把所有服装、年龄或版本一起垫入。支持单个、批量移动及拖拽移动到角色或分类；移到未分类后，明确移动的结果优先于名称、编码自动推断，不能自动拉回原角色。资产库右键菜单保留“移动到…”，不单独显示“移出角色库”。导入当前道具分类的图片明确归为道具，不能因文件名含角色或C编号出现在剧目角色目录。资产默认按序号自然排序，并保留置顶与优先设置。分组卡片的粗体标题采用当前封面图片的名称，小字展示分组名；详情同组变体可以来回切换。道具分类提供虚线“新建道具”卡片，空分类也可新建。人物、场景、道具、音频、视频分类均提供“查看已禁用”区域，默认展开，禁用素材仍不参与自动引用。剧目角色目录去掉“图·音 / 缺音”状态标签，保留头像、名字、数量和置顶描边。在选中角色库内导入音频时，已有声线或文件曾导入过都不阻止归属；同源重复导入不新增多余副本，另一个角色使用中的原资产不被改属。音频资产页整个主内容区域均接收外部文件拖入，包括卡片下方空白；沿当前分类正常导入，避免重复导入或误触提示词替换、侧栏移动，结束、取消或离开时清除虚线反馈。资产库右键不再放两个重新定位入口，定位移到顶部功能区，可先勾选素材后只定位所选；提示词卡片既有绑定/定位不受此项影响。

## 五、渠道、生成与补帧

31. **渠道参数各自独立。** 顶部小云雀、即梦CLI、其他渠道左键沿用切换并打开设置；右键只打开该渠道设置，不改变当前生成渠道。切换即梦、小云雀、Oii 等渠道后，模型能够正常选择，时长、分辨率和参考素材限制采用对应能力。支持4秒的模型不能被错误限制为最低15秒。 提示词参数栏的样片模型名完整显示为 seedance 2.5 draft；收起的画幅比例只显示比例数值，展开后仍保留横屏、竖屏等说明。底部工具栏行内整合视频组切换（`< 序号 >`），置于参数胶囊与重新匹配按钮之间；模型选择器收紧为自适应宽度；时长、画幅比例、清晰度、补帧四个离散控制项整合为一个统一紧凑的“生成参数”胶囊按钮（如 `23s · 16:9 · 480P · 30 FPS ⌄`），点击弹出 Popover 面板进行详细参数选择；面板使用大点击区域和比例图形，点击胶囊中的具体参数直接定位对应设置区，支持关闭和恢复该模型默认参数，不扩展模型不支持的选项；“重新匹配”按钮改为纯图标旋转按钮（去除文字标签，保留完整无障碍提示）；“开始创作 / 开始创作 · 样片”按钮调整为紧凑的圆形向上箭头按钮。

47. **Oii 固定参考。** Oii 设置提供每组固定参考视频开关，默认开启并采用“2秒打折”，可更换素材；仅附加参考文件，不在提示词插入 @。其他渠道不受影响，已生成记录保留提交时素材。

32. **三个生成模式含义保持稳定。** 模式一确认后生成；模式二只建立节点、不生成、不扣生成积分；模式三按用户本次选择直接生成。切换模式不能替以前的草稿自动提交。Oii时长滑杆气泡、数字框和实际提交秒数保持一致，不显示离散选项数组下标。

33. **节点状态写清官网。** 显示“节点已建立 · 即梦官网手动生成”“节点已建立 · 小云雀官网手动生成”等具体渠道名称。

34. **模式二的官网成片能够对应回传。** 在已支持的即梦流程中，用户在原画布手动切换样片、生成或补帧后，按原任务和节点关系取回结果，不能按相似名称误收其他视频。其他渠道的能力须独立核实，不据此宣称均已支持。

35. **官方补帧由工作台自身完成。** 使用已选择的官方后台网页会话方案，不依赖浏览器插件；不能把 AI 临时手动画布、下载再导入，当成工作台自动流程已完成。

36. **补帧三选项与回传结果。** 即梦支持补帧的参数栏仅提供“不补帧、30 FPS、60 FPS”三个选项，默认30 FPS；小云雀及其他不支持的渠道不展示该补帧环节。选择不补帧时返回原生成视频；选择30或60时只返回对应补帧成品。详情显示实际完成的补帧档位，不能按当前下拉框猜测历史视频帧率。此条已由用户明确确认，不再属于待确认项。 参数栏选中值只显示“不补帧 / 30 FPS / 60 FPS”，不加“补帧 · ”前缀，采用与其他参数一致的下拉样式。生成完成后尽快接续补帧，正常等待补帧继续定期查询，不进入需人工核对的低频等待。官方后台操作须等待对应按钮进入可点击位置，不能仅因控件已有布局就点击屏外或被遮挡的位置。

37. **任务身份保持一致。** 即梦新增账号的操作记录使用独立、可安全写入的本机目录；复用该账号原授权，不修改旧目录权限，不因目录错误要求重新登录。旧任务记录及提交ID保留，恢复只核对原任务，不自动补发。 切换账号、项目、画布或重启后，原任务仍按原归属查询和回传；网络失败、刷新或恢复不能造成重复提交、重复扣费。

38. **关闭与退出保持区分。** 右上角关闭进入托盘；托盘“退出工作台”才真正退出。本机个人版固定日常入口为根目录“启动晓晓工作台.vbs”；AI维护后重新打开及用户桌面快捷方式均使用该VBS，保留工作台图标及F盘环境设置。后续更新替换win-unpacked整套程序与资源，VBS及桌面入口保持可用；隔离测试和系统通知注册沿用各自机制。

## 六、性能和验收规则

39. **输入体验属于必须保留的功能。** 长提示词输入、中文输入法、粘贴、撤销重做不能丢字、跳光标或反复闪烁；标题、镜头、字段名、引号和台词高亮，以及引用小图，不能破坏原始提示词。拖选提示词或待补素材卡标题文字后松手不打开@素材库，普通点击绑定入口继续可用。 删除参考图只影响该张图，不把同角色其他参考一起移除；图片、音频、视频、首尾帧、绑定及当前提示词的修改支持Ctrl+Z撤销和Ctrl+Y重做，撤销历史按载入的视频组隔离；重新载入本组恢复该组原参数，不把编辑器临时移除写成永久排除。相邻同角色引用图片分别显示，不能看起来像一个不可分的图片块。关闭素材大图或按Esc返回资产库时，不得短暂切换成窄版编辑表单再消失。

40. **资产按需加载。** 屏幕外大图及其模糊背景避免提前全部加载；没有变化的图片不因切页、切回窗口而反复刷新。性能优化不能以关闭必要的任务回传为代价。

41. **先找原因再优化。** 区分输入重绘、图片加载、文件同步、任务查询等具体耗时，不能仅凭感觉归咎于显卡或后台运行。

42. **按改动范围验收。** 遵守根目录 `AGENTS.md` 的范围测试规则；局部修改不默认全量回归。修过的逻辑问题按实际风险保留能复现它的针对性测试，修改相关逻辑时再运行；不为纯文案或按钮位置变化机械增加测试。

43. **如实报告交付状态。** 分清“代码完成、相关测试通过、已安装、用户确认好用”；未完成或未测试的不能写成通过。真实扣费测试需要对应授权，历史某次试生成许可不作为长期许可。

44. **视频截帧保留原视频。** 视频详情提供作品信息、生成参数与截帧；底部主操作区原“下载视频”替换为“截取视频帧”，其他已有下载入口保留；可以拖动时间轴、前后逐帧或按秒定位，保存后的“去查看”关闭视频详情并定位新资产；暂停的画面按原尺寸保存为PNG，统一存放在原视频所属项目的资产库-视频目录中，不修改原视频。

45. **任务清单与通知定位。** 顶部生成数只统计实际处于生成、建节点或补帧中的任务；待确认、待官网生成、结果待核对和终态不冒充生成中，同一任务历史副本不重复计数。“中断本地等待”停止工作台对该任务的查询与转圈，保留原任务身份，不伪造成生成成功或官网取消；重启不自动恢复，明确选择“恢复原任务查询”只查询原任务、不重新提交扣费。平台是否取消须由真实平台能力确认。可以展开查看具体项目、视频编号和状态，定位到对应视频，并支持在待处理任务列表中右键选择删除。点击生成成功的桌面通知时，唤起工作台并跳到该成片所在项目、目录和视频详情。同一任务审核失败等终态错误仅提醒一次，失败详情保留；后台恢复、切页和刷新不得反复弹同一失败提示，明确失败不重新冒充生成中。

46. **小云雀采用免插件原画布流程。** CLI 上传本组素材、创建视频节点并建立引用；模式二只建节点、不依赖网页登录、不生成。模式一、三由工作台独立官方后台网页会话操作原节点生成，成片按原任务回传并保存到本地工作台。布局沿用即梦的账号、画布、模型、比例、时长、清晰度和三种创作方式；不展示即梦专属补帧。首次登录需用户确认网页与CLI为同一账号，变更身份或提交结果不明时停止，不能重复点击。使用当前账号个人空间，不静默切换团队；不以画布外生成替代该流程。设置主界面集中为账号连接检查和画布连接检查；分别显示CLI授权、官网后台会话及画布实际可访问结果，提供直接登录和连接入口，不把未登录后台会话混称为CLI断连。官网定位流程兼容无“视频”标签的列表及资产侧栏；可直接使用已显示的素材搜索或“资产管理”，定位原节点后收起遮挡参数的资产侧栏；按本次任务唯一名称搜索，并在准备和发送前核对原节点ID、提示词、素材及参数，不能因控件变化创建重复任务。兼容已知小云雀官网域名跳转，仍核对同一项目、画布与网页身份；不能因为新官网域名误报未登录，也不能放宽到其他网站或其他画布。

48. **Agent 模式与辅助创作。** 工作台集成 Agent 辅助修改提示词与脚本创作：视频卡片悬浮“发给 Agent”或右键可将视频提示词与上下文直接送入 Agent 对话侧栏；Agent 思考与生成过程中，旋转中的圆形加载按钮支持点击暂停/停止，安全中止后台正在执行的 Codex 子进程或自定义 API 请求，并标记为“已暂停思考”，避免卡死等待；提示词输入框上方提供快捷指令胶囊，支持自定义编辑管理（自由增删、重命名常用改写指令，本地持久化）；顶部支持 Codex 本地可用模型选择与切换，并支持配置自定义 OpenAI 兼容接口（Base URL、API Key 与 Model 名称），自定义API密钥采用Windows当前用户加密持久化，前端只保存配置元信息。DeepSeek提供官方预设、模型列表连接检查、超时与停止保护；格式不完整的回复不得覆盖提示词，切换项目/视频组或用户已编辑正文/参数、取消自动回填后，旧回复不自动回填。Agent仅提出/应用修改，不以聊天指令自动授权视频扣费生成。侧栏与视频台衔接（2026-11-04）：侧栏滑入打开；点击收起时立即停止本次思考，再滑出并移除侧栏（与原先收起即停止一致）；交界处可拖动调整宽度（320–640像素，双击恢复380，加宽按钮切换到520），宽度记住；思考中标题栏显示扫描线；回复默认显示与发送时原提示词的修改对比（只用于显示，不参与回填判断），可切换修改后全文；底部“定位”在视频台中滚动到并高亮当前目标视频；Agent填入提示词时提示词面板短暂发光提示。

## 七、未确认或未完成事项的边界

- **提示词具体配色未固定。** 保留第39条的高亮能力和可读性；没有用户最终配色表，不擅自声称某一组颜色已被永久确认。
- **小云雀真实生成仍需验收。** 已确认采用第46条的CLI与官方后台会话组合；官方CLI本身没有指定画布节点开始生成命令，不能称为纯CLI全流程。只有建节点、上传图片或下载旧成片，不代表新任务端到端已完成。真实扣费测试须取得本次授权。
- **快捷方式导入高清软件仍仅限方案讨论。** 用户当时明确要求先看方案、不实施；没有后续授权，不擅自执行转换、复制或更改保存方式。
- **最近性能修复的实际体验尚无用户验收结论。** 用户告知另一个 AI 已完成收尾，不等于用户已经确认所有匹配和卡顿问题解决。接手须核对最新版本及交接记录，继续区分技术检查与真实体验。

上述事项只有在取得相应确认或完成验证后才更新状态，不因用户没有继续提及而自动视为完成。
