## 三、所有方案共同的排版改进

1. **顶部栏**：项目页签改为卡片式，运行中页签带旋转图标、出错带红色“!”；“N 个任务生成中”改为胶囊，点开仍是原任务列表（定位、右键删除）；渠道“小云雀 / 即梦 CLI / 其他渠道”改为分段控件（左键切换、右键看设置的行为不变）。
2. **最左功能栏**：入口顺序和名称不变；“自动发送”前保留分隔线；选中项更醒目。顶部按钮收起功能栏照旧。
3. **项目目录栏**：“视频 / 资产”切换做成分段控件并显示数量；文件夹层级缩进更紧凑；仍可拖动调宽、向左拖到底或双击收起为图标栏。
4. **视频页工具栏**：分成“创作控制”（Agent、三种创作方式、自动匹配开关）和“视图管理”（选择、颜色分组、筛选、视图、全局提示词、导入视频组）两组，中间用细竖线分隔，1440 宽度下单行排布；自动匹配开关仍在顶部工具栏。
5. **视频卡片**：保持**直角纯画面**，不加标题等说明区；右上角悬浮按钮顺序仍为 重新编辑 → 发给 Agent → 收藏；颜色圆点、备注即时提示、未查看小圆点位置不变；“生成中”增加底部进度条，“失败”使用斜纹底并显示原因，“载入本组”占位卡改为虚线框。
6. **浮动提示词面板**：毛玻璃浮层，面板外左右保持透明；参考素材卡统一尺寸、带序号角标，悬停显示“绑定 / 定位”与删除；缺失素材显示虚线“待补”卡；提示词高亮区分标题、镜头、字段名、台词引号、@ 引用（缺失引用用波浪下划线）；底部依次为 @、模型（完整显示 seedance 2.5 draft）、生成参数胶囊、`< V07 >` 视频组切换、垃圾桶、收起、纯图标重新匹配、圆形向上箭头开始创作。
7. **生成参数面板**：胶囊中点击某一项（如“16:9”）会直接打开并定位到对应设置区；时长滑杆、比例图形、清晰度与补帧（不补帧 / 30 FPS / 60 FPS）使用大点击区域；底部“恢复该模型默认参数”。
8. **Agent 侧栏**：标题下显示模型徽标（点击进入模型配置）与就绪状态；顶部显示“当前对象”；快捷指令胶囊可编辑；自动回填开关；思考中旋转环按钮可点击暂停，显示“已暂停思考”。
9. **项目资产**：剧目角色目录头像，置顶人物带彩色描边；分组卡粗体标题为封面图片名称、小字为分组名；“优先 / 已禁用”角标；“查看已禁用”默认展开且图片清晰显示；右侧检查器字段只保留 名称、别名（多个）、分类、优先级 / 禁用、角色 / 分组。
10. **视频详情**：备注显示在“作品信息与生成详情”上方；提示词置顶箭头在“复制”右侧；置底箭头在底部操作区右侧；底部主按钮为“截取视频帧”。

## 四、需要你确认的显示差异

以下几项只改显示，不改业务逻辑，但和现在看到的样子不同，请一并确认：

1. **视频卡片编号避让**：悬停或勾选时，勾选圆圈出现在左上角，编号会向右移开，避免两者重叠（现在两者会叠在一起）。
2. **资产页工具栏变紧凑**：在检查器打开时，“筛选”“视图”改为只显示图标（悬停有文字提示）；顶部定位按钮显示为“定位”（提示文字说明“勾选后只定位所选”）。
3. **Agent 回复中的修改对比卡**（− 原句 / + 新句 +“应用到提示词”）是**建议样式**。本机接回前需要核对现有回复数据能否提供原句与新句；如果不能，会保留现有回复展示，只套用新配色。
4. 方案 B / C / D 是否替换默认皮肤，或者作为现有皮肤的升级并存（见第二节建议）。
