# 晓晓工作台 UI 源码交接包

这是给云端 AI 做界面设计并直接编写可合并代码的前端源码快照。用户希望收到改好的源码，再交给本机 AI 整合、验证、打包和安装。

## 使用方法

1. 将整个 ZIP 上传到对方云端并解压，不需要上传完整工作台、安装包或个人数据。
2. 将同目录《给云端AI的任务说明.md》作为任务消息发送，让对方直接完成设计和编码。
3. 用户如有喜欢的风格或当前截图，可另外补充；本包没有界面截图和真实项目素材。
4. 对方完成后，下载其返回的源码 ZIP、改动清单和预览截图，一起交回本机 AI。

## 基线

- 本机个人版源码 package.json：0.5.22。
- 原启动 VBS 指向的 desktop-app/dist/win-unpacked/resources/app.asar 内版本：0.5.21。该项为磁盘程序包核对，未核验正在运行的进程。
- 因此本包采用当前源码快照，不能声称与当前运行界面逐项相同。
- 前端自身 package.json 的 0.1.0 以及 infinite-canvas/VERSION 是上游子项目版本，不代表桌面个人版版本。
- 原始文件 SHA-256 记录在 manifest.json；本机以后按清单比较合并，不能用整个旧目录覆盖当时最新源码。

## 包含内容

- infinite-canvas/web/src：当前 Next.js / React / TypeScript 页面、组件、样式、hooks、stores、types、services，以及 Next 的 API route 实现源码。
- infinite-canvas/web/public：前端静态资源；保留已编译的 3D 导演台和模型资源，以免相关页面引用缺失。
- 前端 package.json、现有锁文件、TypeScript / Next / Tailwind 配置。
- infinite-canvas/VERSION、CHANGELOG.md、LICENSE：现有配置读取所需的版本说明及许可证。
- reference：当前本机功能保留规则和维护规则，作为行为约束。

没有包含 Electron 主程序、Go 后端、账号配置、授权会话、浏览器资料目录、真实剧目素材、工作台项目数据库、日志、历史备份、node_modules、.next、安装包。public 下 3 个 ComfyBridge 平台可执行文件已排除；本次界面设计无需使用它们。保留的 API route 是程序实现，不是账号数据。

## 云端预览说明

这是前端交接包，不是完整云端工作台。真实本地文件、账号连接、任务查询和生成依赖本机服务，云端不能据此验收这些流程。

在 infinite-canvas/web 内可先 npm ci，然后 npm run dev。原 build 脚本还会调用未包含的 ../canvas-agent 脚本；界面构建检查可用 npx next build，类型检查用 npx tsc --noEmit。现有 next.config.ts 的 ignoreBuildErrors=true，构建成功不等于类型检查通过。

云端 AI 应建立独立的 design-preview 路由或预览目录，用虚构的项目、资产、视频和任务状态演示页面；预览模拟代码应与生产 API / store 清楚分开。具体启动命令和地址须由交付方实际运行后填写，不得把未运行的检查写成通过。

本包只复制源码并新增交接文档，没有改动、构建或安装原工作台，也没有更改已确认的功能规则。
