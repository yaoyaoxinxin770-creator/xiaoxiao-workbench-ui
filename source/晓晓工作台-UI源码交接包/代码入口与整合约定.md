以下路径均相对于 infinite-canvas/web。

| 视频列表、目录和卡片 | src/app/(user)/video/components/video-studio.tsx |
| Agent 对话侧栏 | src/app/(user)/video/components/codex-agent-panel.tsx |

主界面是 Next.js 页面。public/xiaoxiao 内的 HTML/JS 属于旧场景兼容资源，保留不等于本轮应以它们为主界面改版入口。跨项目公共素材页和当前项目的角色/场景资产库也不是同一功能，不要混用。

## 合并要求

- 在现有页面组件中调整 JSX 和样式时，保留原有事件处理、组件参数、业务回调，以及被代码读取的 id / data-* / DOM 结构约定。有必要移动结构时，同步列出受影响选择器。
- 优先修改样式和展示组件，避免把大型视频页、store 或接口模块整文件改写。交付应便于本机按差异审阅。
- 真实服务调用继续沿用原接口；preview 的假数据、假任务和模拟回调单独组织。不得以“接口暂时不可用”为由删除按钮或业务连接。
- Next 内 src/app/api 和 src/lib/agent-settings.ts 含本机 Agent / 设置实现，它们供了解调用关系，本轮不得把其重写为云端服务。
- 本机 AI 接回时根据 manifest.json 校验基线、比较此后修改并逐文件合并，再执行按影响范围的个人版验证。不得把整个旧源码目录直接覆盖本机最新目录。
- 当前仅维护个人版，分享版与分享版测试不属于本次范围。真实扣费生成须另有本次授权。

## 演示覆盖建议

- 正常窗口和较窄窗口：导航展开/收起、目录伸缩、长模型名与完整生成参数。
- 有内容与空状态：多个项目、不同目录、同组多版本视频、生成中和失败状态。
- 项目资产：角色、场景、道具、音频、视频；多变体、优先和禁用显示、详情弹窗。
- 提示词：长正文、高亮、图片/音频/视频参考、缺失素材、面板收起和展开。
- Agent：输入、处理中、暂停和回复展示；保留回填相关开关及原有连接。

这些项目是展示和本机复核清单，不代表源码当前每项已经实现或通过验收。
